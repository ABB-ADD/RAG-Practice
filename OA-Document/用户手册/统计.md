# 统计

多级填报中附带自定义统计模块，
在自定义统计报表中，可根据需要设置柱状图、饼图和折线图。可添加多级填报下挂的表单作为数据源，创建自定义统计图表卡片，分析多级填报数据。

操作步骤：

1、点击【新建自定义统计】按钮，输入统计名称，点击确定。

![](https://dl.eteams.cn/site/8a94f521-12f6-4e63-a868-bdbcc7024de0?imageType=png)

2、完成统计名称输入后，会进入页面设计器界面，此处提供部分图表类组件以供使用。

![](https://dl.eteams.cn/site/bc19dedf-d6bf-4225-bea3-2dbd93b0c647?imageType=png)

3、创建完成后，统计卡片即可显示在页面中。

![](https://dl.eteams.cn/site/56f386b5-505d-4604-b2d5-ac48ed41fdaa?imageType=png)
