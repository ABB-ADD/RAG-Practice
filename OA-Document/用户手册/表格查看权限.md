# 表格查看权限

**表格查看权限表格视图支持设置查看权限**，仅拥有查看权限的用户可以在前台查看视图页面，设置入口如下图所示：

![](https://dl.eteams.cn/site/b8ede04e-4ecd-43b3-8d73-83889b891917?imageType=png)

点击“表格查看权限”，打开设置弹窗，支持通过人员、部门、群组、所有人、岗位、兼职岗位、职级、外部人员、所有外部人员、角色等10中不同维度添加权限。

![](https://dl.eteams.cn/site/f5d74e65-a155-4d2a-b9c7-5a03ec4d3a93?imageType=png)
