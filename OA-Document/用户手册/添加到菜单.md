# 添加到菜单

**添加到菜单通常情况下**，用户需要在前台菜单中访问到表格视图页面，需要在应用的菜单设置中添加菜单并选择到当前表格。为了改善体验，集中设置项，在表格视图的设置菜单中，支持通过点击“添加到菜单”，将当前表格视图快捷配置到应用前台菜单设置中，如图所示：

![](https://dl.eteams.cn/site/79be7797-6657-4655-9270-056c8fe79278?imageType=png)

点击添加到菜单，弹出菜单设置弹窗，弹窗中已自动配置好链接地址为当前表格视图，用户仅需设置权限、参数等其他配置项即可

![](https://dl.eteams.cn/site/ca231bb8-8f2a-4d22-a0c0-57e4ba6788c1?imageType=png)
