# 条件参数

**一、概述**

条件参数，支持三种模式分别为条件参数、自身值和动态参数；即在筛选条件中对字段设置条件参数/默认值/**动态参数直接对数据进行过滤条件参数支持所有关联类型**、文本类型、下拉框类型、数值类型以及日期 时间类型的字段等

![](https://dl.eteams.cn/site/85fa6d3d-8de6-4205-ac3c-dfc0304fdaf9 "20211110165356_699.png")

**二、功能说明**

1、条件参数：设置条件参数后，可获取到url上的值来过滤数据

![](https://dl.eteams.cn/site/50c39a3d-7424-4b43-966c-0dae73e41e11 "20211110165647_552.png")

（2）自身值：自身值即给条件设置条件默认值，打开前端页面时直接根据条件默认值进行搜索

![](https://dl.eteams.cn/site/902ac83d-9ad8-48d4-bcf4-1c371de13bb3 "20211110165942_248.png")

（3）动态参数：组织、人员、日期类型的字段支持设置动态参数为条件默认值。支持添加对应类型的系统动态参数作为条件值进行搜索，筛选时获取动态参数并解析。

![](https://dl.eteams.cn/site/f09c0a75-3f4e-40f9-8a97-487118615e3e?imageType=png)
