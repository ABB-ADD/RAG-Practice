# 页面事件

## 一、**概述页面事件支持单击或加载完成时**，执行动作

## 二、**功能说明场景**：根据打开当前页面时，所登录的账号，动态显隐导航面板的每一项，**比如当账号人员是产品部门时**，导航面板显示需求收集，需求评估，需求研发，缺陷收集，缺陷评估，**缺陷解决当账号人员是测试部门时**，导航面板显示需求评估，
缺陷收集，缺陷评估，**缺陷解决当账号人员是开发部门时**，
导航面板显示需求评估，
需求研发，缺陷收集，缺陷评估，缺陷解决

![](https://dl.eteams.cn/site/e2bac49a-95b6-4968-9d51-ce14ebdfc7ad?imageType=png)

配置如下：

![](https://dl.eteams.cn/site/72dc58fb-e57c-40d7-b4a3-79ec1c33d696?imageType=png)

配置触发事件为：页面加载完成时

if  当前账号部门名称=‘产品部’，显示隐藏组件中选择管理中心组件，显示全部子项

else if  当前账号部门名称=‘测试部’，显示隐藏组件中选择管理中心组件，隐藏需求收集，需求评估，需求研发

else if  当前账号部门名称=‘开发部’，显示隐藏组件中选择管理中心组件，隐藏需求收集
