# 输入类

1.**实时数据输入源顾名思义**，实时的获取表中的数据。目前只支持mysql，并且需要开启binlog。

* 数据库连接：选择需要抽取表的连接，连接可在
  [数据连接](https://eteams.cn/community/help/1974435237094594001)
  中维护。
* 数据库表：根据连接选择需要同步的表。

![](https://dl.eteams.cn/site/b372e3eb-900e-4942-89cd-8c5f3af375d8?imageType=png)

数据预览:根据选择的表信息，获取其中部分数据。

![](https://dl.eteams.cn/site/5f91f1c3-c2d7-4686-a630-7a6e50add2de?imageType=png)

2.**维度数据源非实时数据源**，根据配置从指定表中获取纬度数据。

* 数据库连接：选择需要抽取表的连接，连接可在
  [数据连接](https://eteams.cn/community/help/1974435237094594001)
  中维护。
* 数据库表：根据连接选择需要同步的表。

![](https://dl.eteams.cn/site/56ea5d59-c76d-4761-a896-5bb34154884a?imageType=png)

数据预览:根据选择的表信息，获取其中部分数据。
