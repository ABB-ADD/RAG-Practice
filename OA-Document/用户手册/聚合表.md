# 聚合表

一、**功能背景用户在数据加工时无法直接利用**eb的单表数据和多表数据进行数据过滤、数据关联、数据指标的计算、聚合表的制作，而通过其他的功能操作比较复杂，操作难度较高。

二、**功能价值通过增加聚合表功能可以降低**eb表单数据处理的操作难度，还大大减少eb表单的数据处理以及聚合报表制作的时间
。

三、功能概述

1. 聚合表新建

2. EB报表选择（单表、多表关联）

3. 数据筛选条件设置

4. 聚合表行表头的设置以及指标的计算

5. **数据预览四**、业务流程图

![](https://dl.eteams.cn/site/6cbd24f7-924a-4eaf-8b05-8c2d86cdcc4e?imageType=png)

五、功能详细说明

1.  聚合表新建

+ 点击数据加工--> 数据准备 -->
  默认分组（选择自己的分组）--> 新建聚合表

  ![](https://dl.eteams.cn/site/19218d5a-1266-4b7b-8b95-feb47c881126?imageType=png)

2. EB报表的选择

+ 进行聚合表相关设置，首先输入聚合表的名称，然后选择数据来源，数据来源于EB表单，可以是单个eb表单，也可以是多个eb报表的关联

  ![](https://dl.eteams.cn/site/42fec5cf-2e3b-4b83-a179-0c6334e96f12?imageType=png)

3. 筛选条件的设置

+ 选择好eb报表之后，如果需要对表单的数据进行筛选，需要设置筛选条件

  ![](https://dl.eteams.cn/site/1dada0f2-7dfa-45f4-8239-0e51efce34ca?imageType=png)

4. 行表头以及计算指标的设置

+ 设置完筛选条件后，需要进行聚合表的行表头设置以及聚合的指标的设置

  ![](https://dl.eteams.cn/site/14a70933-ef53-47c0-b2df-936fe2d985e3?imageType=png)
+ 设置需要聚合的指标，可使用指标计算器组件进行指标的计算公式设置，左侧列出所有可以计算的字段。

  ![](https://dl.eteams.cn/site/1a27d2de-b0fb-4674-8d88-fd8bdaa9793e?imageType=png)

5. 聚合表数据预览

+ 设置完成后，可以进行数据的预览和展示

  ![](https://dl.eteams.cn/site/9aabb660-e36b-48da-b857-03da39046b29?imageType=png)

六、**使用和维护权限该功能用于设置数据集的使用**、编辑权限

![](https://dl.eteams.cn/site/919eb8a8-5737-4382-9f2f-d5eed39989af?imageType=png)

维护权限：

* 可以对数据集的操作：查看、编辑、删除、移动分组、重命名、开启关闭缓存、给他人分配权限
* 系统管理员：拥有租户下的所有数据集的维护权限
* 创建人：**拥有自己创建的数据集的维护权限使用权限**：

* 可以对数据集的操作：
  查看、**卡片预览数据权限分配**：人员、部门、分部、角色、岗位、**所有人七**、**上下游关联功能点当制作完聚合表数据源之后**，可以在数据源的公共前端组件中选择到该数据源，可对聚合表进行后续的数据加工或者页面展示等操作

![](https://dl.eteams.cn/site/c0f50c2c-5660-43a9-a36f-55e8d91eb13f?imageType=png)
