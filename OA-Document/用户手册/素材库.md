# 素材库

素材库是集中管理e-Builder中的图标素材以及图片素材的一个资源库，其中囊括系统的素材以及个人上传的素材两大类。

素材库支持管理图标、图片、视频，通过【页面设计器】-【左上角隐藏菜单】-【素材库】进入对应的素材库：

![](https://dl.eteams.cn/site/2f33b626-07ab-48c8-9ac5-5c6ad5cfe314)

图标管理：

![](https://dl.eteams.cn/site/630617bd-41eb-47b8-b70f-fc3f5179ab2a)

图片管理：

![](https://dl.eteams.cn/site/6ca20295-6bb8-4492-9183-bbab9dc88030)

视频管理：

![](https://dl.eteams.cn/site/a5404ceb-c0b0-43ed-a1fc-9be7c82d5230)

素材库预置了常用的图标、图片、视频，预置的系统素材不支持调整。素材库支持个人上传素材，在我的素材下新建文件夹：

![](https://dl.eteams.cn/site/afd3283c-290d-4d25-bf95-092005d23ba1)

在文件夹下可上传对应的素材：

![](https://dl.eteams.cn/site/1b6d862e-b72f-4ff0-baea-9beee8373311?imgType=gif "20211110174413_971.gif")

素材库支持以下操作：

![](https://dl.eteams.cn/site/6bc07ab4-fd69-4ca0-80fd-2bc50f26721e?imgType=gif "20211110175039_722.gif")

1、支持按名称、大小、创建时间排序。

2、支持栅格布局和列表布局。

3、支持移动和删除（只能移动和删除自己创建的素材，其他用户创建的素材支持查看，不支持操作）

4、针对视频类型的素材，还支持播放。

![](https://dl.eteams.cn/site/c8eddb09-3d9b-4fbf-a1cc-11f2a07a2c67)
