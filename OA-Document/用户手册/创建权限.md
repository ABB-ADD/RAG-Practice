# 创建权限

创建权限用来控制哪些用户可以在该表单下创建数据，支持人员、部门、群组、所有人、岗位、兼职岗位、职级、外部人员、所有外部人员、角色共10种类型。

![](https://dl.eteams.cn/site/0f0760a2-e7de-4478-8a51-515593490d70?imageType=png "20220315193813_350.png")

有创建权限的用户，在表格右上角会显示【新建】按钮，无权限则不显示：

![](https://dl.eteams.cn/site/c2f1bce3-2dc7-45e7-9eea-ae494c17d203?imageType=png "20220315194208_688.png")
