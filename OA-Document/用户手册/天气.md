# 天气

【天气】是用来展示某个城市天气的元素，支持展示当前城市或自定义城市。

![](https://dl.eteams.cn/site/0b112fc2-406f-4fe7-ae0c-3842bc0738cd?imageType=png)

将【天气】拖动到设计器面板中，在右侧属性面板中定义城市：

![](https://dl.eteams.cn/site/09c5be90-62b5-4dd1-8934-444d2af97ac9?imageType=png)

1、城市：可选当前城市、指定城市，当前城市需要获取定位信息后才可使用，选择指定城市后，输入城市名称：

![](https://dl.eteams.cn/site/8d84a28a-ee6e-4c29-92e2-60b8e0368bb6?imageType=png)

说明：支持多个城市（以半角逗号分隔）。

2、自动滚动：展示多个城市时，是否自动滚动数据。

天气组件支持切换样式，系统提供3种样式可选择：

![](https://dl.eteams.cn/site/317b72c4-6c4a-4e9a-872a-b551a0b70b9e?imageType=png)

说明：天气元素依赖weather.com.cn网站的数据接口，如果weather.com.cn网站数据接口后续不能使用或者需要收费，天气元素也无法正常使用。
