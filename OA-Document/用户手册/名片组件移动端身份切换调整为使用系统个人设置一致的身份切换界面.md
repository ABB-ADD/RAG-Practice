# 名片组件移动端身份切换调整为使用系统个人设置一致的身份切换界面

**功能背景**

目前移动端名片可以通过开启显示所有身份切换账号信息，只能浏览相关账户信息。现在存在客户需要能够切换当前用户主次身份进行登录操作。

**功能描述**

在移动端配置添加一个启用主次身份切换的开关，开启后调用主框架提供的主次账号页面进行切换账号操作。

**功能说明**

1、名片组件，移动端用户来源选择当前用户时，启用显示所有身份后出现启用主次身份切换的按钮

![](https://dl.eteams.cn/site/75a21fa7-9eec-4b28-8da4-ce194d53190b?imageType=png)

2、启用后，若当前用户存在主次身份，预览时点击三角图标可展示当前用户的所有主次身份，点击其他身份后可直接切换当前系统的登录人。

![](https://dl.eteams.cn/site/3b1699ed-38b5-488b-98a8-21a9315bbd92?imageType=png)
