# 历史版本

历史版本：

报表支持保存为新版本，以及查看和还原历史版本

（1）保存为新版本

![](https://dl.eteams.cn/site/7766171b-d706-47c6-b868-a8c125fbae02?imageType=png)

如图所示，点击保存按钮右侧的【存为新版本】，可将当前设计的报表保存为一个新版本，这样保存不会导致原来的版本被覆盖后无法找回。

（2）预览和还原历史版本

![](https://dl.eteams.cn/site/703e801f-742a-4af8-946d-1601da0887c9?imageType=png)

点击右上角的“历史版本”按钮，会弹窗打开显示当前报表的历史版本，可对某一个历史版本进行预览和还原操作；所有存为新版本的数据都可以在这里进行管理。

还原后可使用对应版本的报表。
