# 表单转移

一、**简介表单转移会将表单从当前所在应用移动至另一个应用下**

![](https://dl.eteams.cn/site/f2d83bed-f710-47d3-b872-b58a15f40f56?imageType=png)

二、**表单转移设置转移应用**：点击【转移到】后，弹窗设置转移的目标应用，仅支持选择当前人员有管理权限的应用

![](https://dl.eteams.cn/site/69a551a3-2955-46f9-9391-ce80b9adb018?imageType=png)

重名校验：**新应用下已有同名表单时提示流程重名校验**：由于转移时关联的流程将一起转移，**新应用下有同名流程时也会提示日志**：表单日志中将记录转移操作、操作人、转移前应用、转移后应用

![](https://dl.eteams.cn/site/094f2e45-88ac-4739-a535-8ef71d20da78?imageType=png)

三、表单转移效果

1、表单转移后，关联了此表单的消息提醒也将转移至对应应用下

2、引用了该表单的动作流组件上，相应应用将会更改为转移后的应用

3、表单转移后，该表单相关的自定义接口也将转移至对应应用下

4、表单转移后，引用了当前表单的流程也将转移至对应应用下
