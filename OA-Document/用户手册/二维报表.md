# 二维报表

【二维报表】是以横向维度、纵向维度2个维度对数据进行统计的一种组件，效果如下：

![](https://dl.eteams.cn/site/76d3b2e7-e495-4538-a2d7-eec8bec73d07)

将【二维报表】拖动到设计区域，右侧属性面板中设置数据源、横向维度、纵向维度、指标：

![](https://dl.eteams.cn/site/597449f6-6fd3-4f57-bbe2-36a9f33f5078)

1、数据源：二维报表的数据来源，与其他统计类组件一样，支持eb表单和数据仓库。
  
2、横向维度：水平方向上扩展的统计维度，支持添加多个横向维度。点击设置按钮，可以设置横向维度的属性：

![](https://dl.eteams.cn/site/d7c21303-be09-455d-bd92-9ef29d254873)

3、纵向维度：垂直方向上扩展的统计维度，支持添加多个纵向维度。点击设置按钮，可以设置纵向维度的属性：

![](https://dl.eteams.cn/site/d44793b2-8e4e-44d0-9b53-d7ff776bb2f8)

4、指标：需要进行统计的度量指标，支持添加多个指标。点击设置按钮，可以设置指标的统计方式、显示格式等：
  
![](https://dl.eteams.cn/site/fa058303-2beb-4ac2-a6a5-382d70dfb4b1)

![](https://dl.eteams.cn/site/826bd885-7b11-41a0-bb39-a4045f463875)

指标的数值格式支持数字，百分比，数字（百分比）等格式。

![](https://dl.eteams.cn/site/4608455b-23a5-4418-84b1-6a996102a2b8?imageType=png)

5、合计：支持开启行合计、列合计、行分组合计、列分组合计，以及合计显示的位置：

![](https://dl.eteams.cn/site/742edc84-c161-4a5f-9851-8cd5ff1fae66)

设置后效果如下：

![](https://dl.eteams.cn/site/1a81395b-5dbb-4bdd-bd1e-42738c1230f9)

![](https://dl.eteams.cn/site/39b4316f-a927-4882-b357-6fd6f02e17db)

6、条件：二维报表数据条件过滤。

![](https://dl.eteams.cn/site/e1a3dc55-d143-4ef7-91ed-bab95b59acdd)

7、格式：设置图表的显示格式

![](https://dl.eteams.cn/site/898ff927-f381-441a-91e9-a913d4b7daf8?imageType=png)

（1）开启分页：开关默认关闭，开启时可实现分页效果；

（2）显示序号：开关默认开启，关闭时可不显示首列的序号。

8、链接：可以设置二维报表的链接动作，点击打开页面、表格视图台账等，并且可以用二维报表的维度字段，作为参数进行传递：

![](https://dl.eteams.cn/site/2d5bfcc8-afa9-4a92-ba89-a149c5336d47?imageType=png)

9、导出成excel：二维报表支持导出成excel，在标题设置中，开启该功能即可：

![](https://dl.eteams.cn/site/83175554-4947-4764-bf21-71b23d0fe0c1?imageType=png)
