# 新建流程

【新建审批】展示的是当前用户常用的审批或收藏的审批，点击审批名称可以快速发起审批。

![](https://dl.eteams.cn/site/49188578-52b8-406c-863a-4b41141a4c0e "20211207095600_853.gif")

新建审批支持自定义类型，即可以选择自由选择相关的审批流程，点击快速发起审批流程

![](https://docimg6.docs.qq.com/image/779FpK9jMGlkWyG8ATp9gQ.gif?w=1280&h=621.196222455404&type=image/gif)
![](https://dl.eteams.cn/site/4f28e08e-2532-40f0-a1e6-3f56e2f6c0ed?imageType=gif)

将【新建审批】拖动到设计器面板中，在右侧属性面板中设置新建审批的显示条数等：

![](https://dl.eteams.cn/site/70c7f5be-a888-460e-a043-f518a141f105)

1、启用底部区域：启用后底部显示分页、进入审批按钮。

2、显示行数：审批的单页显示数量，默认为5.

3、显示布局：支持1列、2列。

4、类型：审批的类型，支持常用审批、我的收藏以及自定义。

当右侧属性面板中的类型选择【自定义】时，选择审批流属性展示，点击“+”，即可选择添加相关审批流程

![](https://dl.eteams.cn/site/d715ee9e-79a8-439a-b35b-0cfe149aaaf1?imageType=png)

说明：新建审批的常用审批和我的收藏都来源于审批模块，当审批模块开启了启用个人审批流时，新建审批也支持个人审批流。
