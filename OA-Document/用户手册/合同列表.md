# 合同列表

﻿

合同列表是以列表形式将合同展示在页面中，可以根据需要显示合同数据。

![](https://dl.eteams.cn/site/ad42e80a-2c2d-4d7c-916b-434480b45c93?imageType=png)

**场景说明**

如需要在页面中展示合同列表，则可以将合同列表拖入页面，设置想要展示的字段在列表中展示。

![](https://dl.eteams.cn/site/2d74563f-1e71-40d5-aba0-dccc057bae6e?imageType=png)

设置项说明：

1、列表样式：设置合同列表按照列表式或表格式显示；

2、显示字段：列表中的合同数据显示哪些字段；

3、数据过滤：支持设置按类型搜索或按条件搜索，设置后，列表中仅显示满足过滤条件的数据；

4、排序字段：设置列表中的数据依据哪些字段排序；

5、每页行数：合同数据每页显示多少行；

6、显示总数：在标题处显示当前列表的合同总数。
