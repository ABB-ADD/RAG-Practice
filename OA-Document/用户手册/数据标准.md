# 数据标准

**一、功能概述**

数据标准模块集合了系统数据集管理和元数据管理两个功能:

+ [系统数据集管理](https://eteams.cn/community/help/1974435424048994006)
+ [元数据管理](https://eteams.cn/community/help/1974436811156194039)

**二、功能详细**

**1.入口**

+ 进入数据加工，点击数据标准TAB可以进入数据标准页,左侧展示系统数据集管理和元数据管理，点击进入对应功能页

  ![](https://dl.eteams.cn/site/7ce5b9a5-b48d-4f17-91e8-00a9b5399f8c?imageType=png)

**2.搜索**

+ 搜索可以直接模糊搜索元数据管理下的表

  ![](https://dl.eteams.cn/site/fc66907a-b2ae-46f7-a93d-9a1badd4a6fd?imageType=png)
+ 系统数据集的内容需要点击系统数据集管理后在系统数据集下搜索

  ![](https://dl.eteams.cn/site/c915d44d-2c67-42ce-8336-4395cf6937e1?imageType=png)
