# 其他的常见问题

**一、权限相关**

**1、为什么我看不到数据集、连接**

* 数据集需要有权限才可以查看使用

+ 系统管理员拥有查看所有数据集、连接的权限
+ 创建人拥有自己创建的数据集、连接的权限
+ 其他人需要系统管理员或者创建人分配权限才能查看
+ 配置权限入口：

  ![](https://dl.eteams.cn/site/a5250426-022f-4a67-8668-fd0bd1d7f2df?imageType=png)
+ 维护权限是可以对数据集、连接进行编辑删除等操作；使用权限只能查看到数据集和连接，在数据源使用，不能编辑删除等
+ 数据连接的使用权限可以限制到具体给哪些表使用权限

  ![](https://dl.eteams.cn/site/803adb8e-a61d-4d61-8d7a-a990f92152ae?imageType=png)

**2、使用dml组件时报错没有dml权限**

**二、抽取表相关**

**1、为什么我的抽取表选不了部分数据库**

* 全量抽取只支持了部分数据库：MySQL、Oracle、OceanBase、达梦、doris、hive、sqlserver
* 增量抽取只支持了MySQL

**2、抽取表是否可以定时运行**

* 使用调度中心可定时调度
