# 字段设置

**一、功能价值**

很多客户想要通过传参的方式去查询一些数据，所以需要在SQL里写占位符，字段设置可以满足客户的需求，可以简化SQL

**二、功能概述**

通过占位符写法可以自定义变量，通过传参查询不同的数据

**三、功能详细说明**

**1、普通占位符**

* 普通占位符写法：select id from table [where id ={id}]

  ![](https://dl.eteams.cn/site/e6e52162-391c-4156-902d-29694f182b1d?imageType=png)
* 字段设置

+ 可以配置占位符字段的字段类型，
  字段类型：文本、数字、日期、人员、部门、浏览按钮、自定义浏览按钮、自定义系统变量、地区、分部
+ 选择不同类型后，默认值可以根据选择的字段类型对应填入或者选择数据，举例：字段类型选择浏览按钮-客户，默认值则可以直接选择具体的客户

  ![de21375f-c34f-4d7c-a93d-ea03b8d8a0dd](https://dl.eteams.cn/site/de21375f-c34f-4d7c-a93d-ea03b8d8a0dd?imageType=png)
  ![](https://dl.eteams.cn/site/ba54169b-c529-437e-953d-abbe1ec67a8b?imageType=png)

**2、区间占位符**

* 区间占位符写法：SELECT  \*  from table [where create\_time between {time\_start} and {time\_end} ]

+ 区间占位符只支持时间区间、数值区间

  ![](https://dl.eteams.cn/site/52d1592c-50a4-42ca-a55a-df590e265d65?imageType=png)

**3、占位符可多选**

* 字段类型为：
  文本、数字、人员、部门、浏览按钮、自定义浏览按钮、分部时支持多选
* 多选按钮为高亮时可传多个默认值
* 时间区间数值区间不支持多选

  ![](https://dl.eteams.cn/site/324e248c-6a32-4f17-87cc-dda8ff09b7b4?imageType=png)

**4、默认值**

* 若默认值没有填写，则会直接去掉[]内的所有内容

+ 比如原SQL为：
  select id from table [where id ={id}]，不填写默认值实际执行的SQL为：
  select id from table，这样就需要注意一下SQL写法
+ 若写为
  select id from table
  [where id ={id}] and [name ={name}]时，填写了id默认值，没有填写name字段的默认值，SQL则会报错，实际执行的SQL为：
  select id from table

  [where id ={id}] and，所以建议每个占位符都单独用一个[]，例如：
  select id from table

  [where id ={id}]  [and name ={name}]
