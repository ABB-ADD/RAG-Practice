# 帮助提示

帮助提示组件常用于对页面上的某些设置或文字进行相关提示说明。从左侧组件库中搜索“帮助提示”，将组件拖拽到页面设计器中。

![](https://dl.eteams.cn/site/15782574-41dc-4d86-a43a-d3194bb14281?imageType=png)

1、提示内容：支持设置提示的内容，支持多语言，支持插入图片。

![](https://dl.eteams.cn/site/74528671-e6f7-466f-a027-1f9e05b754b3?imageType=png)

2、显示位置：鼠标移入后的提示内容的显示位置，共支持12个位置，如下图所示。

![](https://dl.eteams.cn/site/540e2500-7ac9-4bec-9345-08d653bb2c90?imageType=png)

3、触发方式：支持移入触发、点击触发两种方式；

4、展示样式：设置帮助提示组件的展示样式，支持图标、文字、平铺模式。

![](https://dl.eteams.cn/site/477da26e-9565-44d7-a128-c5520e41b972?imageType=png)

（1）当【展示形式】选择图标时，下方可在素材库中选择对应的图标，以及样式设置（图标的大小、圆角、颜色、填充色）

![](https://dl.eteams.cn/site/0b48e561-002a-4f2f-9707-143191e65058?imageType=png)

**![](https://dl.eteams.cn/site/0e27f6f5-9fea-4108-b1a5-8e9a0e260cf8?imageType=png)**

（2）当【
展示形式
】选择文字时，下方可输入文字内容，以及文字的样式设置（文字大小、颜色、加粗、斜体）

![](https://dl.eteams.cn/site/a746fa0f-a3f4-4f40-ab56-82e51ee67135?imageType=png)

5、提示内容样式：设置提示气泡中内容的样式，支持设置字体颜色、大小、以及内容对齐方式（居左、居中、居右）

![](https://dl.eteams.cn/site/efbe3138-da9d-4224-aa41-a1ade5f24726?imageType=png)
![](https://dl.eteams.cn/site/98e13fb6-04a7-4d4c-b9ee-030824da44c3?imageType=png)

6、
提示气泡样式：设置提示气泡框的样式，支持设置气泡框的宽度、背景色、边框色、以及是否显示气泡箭头

![](https://dl.eteams.cn/site/a337097a-d443-45d1-8e05-227f4cc390fa?imageType=png)
![](https://dl.eteams.cn/site/db229fc7-f284-43ff-b1b0-ab23cacfe969?imageType=png)

注意：设置提示气泡的最大宽度。若提示内容超出最大宽度，则折行显示；若提示内容未超出时，则根据提示内容的宽度显示。注：最大宽度不能小于110px。

7、当【展示形式】选择平铺时，支持直接将帮助提示的内容平铺到页面上展示。

![](https://dl.eteams.cn/site/d56de7b2-5ea8-481d-984e-2b6f513f171b?imageType=png)

（1）图标：平铺提示框中的最左侧的图标，支持自定义选择。也可设置图标的样式，比如图标大小、颜色、背景色等。

![](https://dl.eteams.cn/site/9c1b654b-0689-4367-a9ab-f52c35fe1f1a?imageType=png)

（2）提示内容：提示信息中需要展示的内容。字体颜色、大小等。

![](https://dl.eteams.cn/site/330809e7-c5e0-4606-b415-5e35e06157d3?imageType=png)

（3）提示框背景色、提示框边框色：设置平铺提示框中的背景色跟边框色。

![](https://dl.eteams.cn/site/28efae7f-f477-4cfd-9dcf-c89c2ee008b9?imageType=png)

（4）显示关闭按钮：启用后，平铺提示框中会显示关闭按钮，支持进行关闭操作。

![](https://dl.eteams.cn/site/0c71525c-5144-4f33-bb09-47b55a7e4ba1?imageType=png)

（5）启用折叠：当提示内容占据页面位置过大时，支持折叠功能。

![](https://dl.eteams.cn/site/e9c2251b-fe38-4815-853f-2d500aac83e4?imageType=png)

① 折叠高度：折叠后内容的显示高度（不包含下方箭头所在高度）。当提示内容的高度小于折叠高度时，按提示内容的高度展示，此时不显示折叠按钮。

② 默认折叠：启用后，页面中的帮助提示组件默认折叠展示，可点击箭头进行展开。

8、帮助提示组件同样支持移动端，如下图。

![](https://dl.eteams.cn/site/07019b1f-e5a5-4e9e-8f7f-e735cbe209ff?imageType=png)

（1）
移动端的触发方式默认为点击触发，不支持移入触发方式；

（2）移动端的样式默认为底部弹出方式，支持设置弹出框的背景颜色，以及字体的大小颜色等，其余设置项与PC端一致。
