四、功能详细说明

1、**分支根据指定字段设置子分支的组件**。

![](https://dl.eteams.cn/site/bbc1333f-af42-450e-997a-c92e34a90cd3?imageType=jpg)

分支依据字段：

**根据该字段的值来设置子分支默认分支**：

当分支设置里无法匹配时，**就执行默认的分支分支设置**->分支字段值：

分支依据字段的值和目标子分支的对应关系设置。

接上例：分支依据字段的值为57时，数据流向平均每日单聊数子分支，分支依据字段的值为58时，**数据流向参与群聊数量子分支分支设置**->目标步骤：

对应的子分支起始节点的名称，从下拉框中选择，选择范围是当前节点的所有直接子节点（即，只有当前节点有子节点时，才能从下拉框中选择目标步骤）

2、**左右连接根据设置的**

**连接方式和**

连接字段

，**将两张数据表的数据左右拼接**

**![](https://dl.eteams.cn/site/06c732f7-36cc-48c7-97cb-5563be80fa89?imageType=png)**

第一个、二个步骤：

**可以选择左右连接组件相连接的任意组件连接字段设置**：

选择想要连接的字段，连接字段值相等的数据会左右拼接。**一般选择两张数据表共有的而且值能够一一对应的字段连接类型**：

四种类型：LEFT JOIN(左连接)、RIGHT JOIN(右连接)、INNER JOIN(内连接)、FULL JOIN(外连接)

连接类型->LEFT JOIN左连接：

返回左侧表单的全部数据，根据连接字段逐行匹配并连接右侧表单数据，匹配不到则留空

**![](https://dl.eteams.cn/site/69ed79d6-61a2-4194-a0be-ce633cbfc076?imageType=png)**

连接类型->RIGHT JOIN右连接：

返回右侧表单的全部数据，根据连接字段逐行匹配并连接左侧表单数据，匹配不到则留空

**![](https://dl.eteams.cn/site/763343b9-7bd0-493f-8845-d23233851a42?imageType=png)**

连接类型->INNER JOIN(内连接)：

根据连接字段，返回左右两侧表单连接字段相等的数据，即返回左右两个表单的数据交集

![](https://dl.eteams.cn/site/d60a10f1-3c84-4d2f-a239-1c8402655ea8?imageType=png)

连接类型->FULL JOIN(外连接)：

回左右两侧表单全部数据，根据连接字段逐行匹配，匹配不到则留空。即返回左右两个表单的数据并集

**![](https://dl.eteams.cn/site/bad54077-2c7a-4ddc-9e6e-abe5b14e0656?imageType=png)**

3、**上下合并将多张数据表按照字段对应关系上下拼接**

**![](https://dl.eteams.cn/site/6658c3e3-3825-4642-b6c1-f4e30cd07edf?imageType=png)**

按照字段对应关系上下拼接后，删除最终的数据中字段重复的数据

连接类型->UNION ALL(上下连接)：

4、JSON**解析解析**JSON数据的组件。

![](https://dl.eteams.cn/site/c75488aa-3fec-4d04-aa7d-9e3583f4d94c?imageType=jpg)

Json数据来源：

从字段中获取：选择上一个节点输出的结果字段作为JSON**数据手动上传**：手动上传JSON文件作为JSON**数据字段设置**->字段名称：

自定义一个新的字段名称，用于接收解析出来的值。字段命名须符合命名规范，

字段设置->路径：

指定数据在JSON中的路径。路径解析规则如下：

JSON数据路径规则：

```
            1.'$' 开头: 表示json变量标识
```

```
            2. 读取对象object加 '.'
```

```
            3. 读取数组array 加 '[]'： [index]取对应角标为 index 的值； [*]:取数组全部
```

```
            4. 正则形式的path：暂不支持
```

```
            5. 如果输入的json字符串或路径 path 无效，那么返回NULL
```
