# 新建签署

使用背景：当EB表单数据是以列表的形式存在，而非EB审批流的方式，此时想针对每条EB表单数据发起签署，**就可以使用该功能配置方式**：

打开e-builder应用中心，**点击需要进行配置的应用在**e-builder中可使用电子签相关能力组件，完成发起、签署等动作。

目前开放了新建签署组件，后续将发布更多电子签能力组件，以实现在搭建场景中使用电子签能力。

# 三、使用签署列表数据发起签署

![](https://dl.eteams.cn/site/e851020c-8caf-42ae-944b-4284fac9f7fe?imageType=png)

![](https://dl.eteams.cn/site/37514e9f-c153-4d49-bf84-11266cd7d968?imageType=png)

由于在新建签署组件页面设置了发送签署-回调更新合同状态动作流事件，故刚刚后续的列表数据发起签署后，会将合同状态回调更新到eb表单字段‘签署状态’中

![](https://dl.eteams.cn/site/c8d6c345-addb-446a-affe-0aa38a628dd1?imageType=png)

当将合同签署完成后，又会触发配置的文件完成-回调更新合同状态+签署后文件
