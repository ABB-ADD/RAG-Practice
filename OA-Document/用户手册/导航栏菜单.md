# 导航栏菜单

**功能简介导航栏菜单组件**，主要是用来展示系统导航栏相关菜单，**通常使用场景是搭建特色主题在系统管理后台**/界面配置中心/导航设置中可以自定义导航栏菜单内容，此处仅用于展示导航栏菜单内容

![](https://dl.eteams.cn/site/7c431489-93c1-4cd8-b158-59e2400f5cd2?imageType=png)

配置说明

![](https://dl.eteams.cn/site/290b8f97-71a2-4264-82a6-7ffb07d389dd?imageType=png)

1、显示主导航菜单：主导航对应位置如图所示。可配置显示菜单项 。

2、显示工具栏菜单：工具栏对应位置如图所示

3、显示更多菜单：更多菜单对应位置如图所示

4、排列方式：支持横向和竖向展示

5、对齐方式：横向展示时支持
居左或居右，一般放在左侧时为居左，放在右侧是为居右；竖向展示时，仅支持居中

6、
标准主题下，导航设置中工作消息选择主导航时：

（1）如果pc客户端没有登录，工作消息会显示在导航菜单中；

（2）如果pc客户端登录了，WEB端IM进入静默模式，此时会隐藏导航菜单中的工作消息菜单
