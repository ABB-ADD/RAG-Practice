# 列表组件开启上下级以及数据可选时，支持设置可选层级

**功能背景**

**目前列表组件启用上下级和数据可勾选**
check
框时，可以根据数据中的字段值设置

check

框的禁用条件，但是客户提出希望可以按照树形的层级设置哪些层级可以勾选，哪些层级禁用勾选或者仅支持叶子节点可勾选

。

## **功能描述**

列表组件启用上下级开关开启时，增加层级选择限制配置，可以设置不限制、按可选层级和按禁选层级。

# **功能说明**

列表
-
表格式，启用上下级启用后，默认显示不限制，可以设置不限制、按可选层级、按禁选层级。设置按可选层级
/
按禁选层级时，显示层级设置框，支持设置层级数字，以英文逗号间隔。
