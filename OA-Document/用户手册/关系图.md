# 关系图

# **一、** **功能背景**

关系图的诞生源于人类对复杂关系的可视化需求。当现实世界中的事物联系变得越来越错综复杂时，人们需要一种直观的方式来理解和分析这些关联。数学家欧拉在
18世纪用图论解决了"七桥问题"，奠定了用节点和边表示关系的基础。随着计算机时代的到来，这种抽象方法被广泛应用于社交网络分析、知识图谱构建、交通路径优化等领域。关系图之所以被发明，是因为它能将抽象的关系可视化，帮助我们发现隐藏的模式、识别关键节点，并优化整个系统的连接效率。从科学研究到商业决策，关系图已成为我们理解和驾驭复杂网络不可或缺的工具。

# **二、** **功能概述**

**关系图组件通过可视化连接数据源**，通过节点和连线的形式直观展现事物之间的关联，**让让**

“不可见的关联”变得清晰，是分析、优化和预测复杂系统的关键工具

。

关系图不仅能帮我们发现
"谁和谁有关系"，

自动识别网络中的枢纽节点、关键路径和脆弱环节

；更能找出其中最关键的人物、最短的路径，甚至预测未来可能发生的新联系，让原本让人头疼的复杂问题变得简单明了。

# **四、使用注意点**

1、关系图嵌套在选项卡内，标题的操作按钮启用但“启用标题”按钮关闭时，按钮会显示在选项卡的标签栏上；

2、关系图默认带有的事件动作：单击每一条数据，右侧滑出打开数据列表；

3、关系图配置新窗口打开含同数据源列表页面时，默认将筛选组件和图表本身的过滤条件传给列表；

4、关系图打开页面的参数配置的参数值支持获取“图表相关”字段，即维度项值、指标项数值。
