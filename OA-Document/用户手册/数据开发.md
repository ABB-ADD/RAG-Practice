# 数据开发

**一、功能概述**

在数据开发页面，可以使用ETL、流计算、抽取表、离线计算作业、python作业功能；也可以通过新建编辑分组的方式实现分组管理；还可以对所有数据集进行一个整体预览查询，分类查询，实现快速查找到想用数据集

**二、功能汇总**

1. [**ETL**](https://eteams.cn/community/help/1974470605417394143)
2. [**流计算**](https://eteams.cn/community/help/1974669258954295982)
3. [**抽取表**](https://eteams.cn/community/help/1974669262254995984)
4. [**离线计算作业**](https://eteams.cn/community/help/1974669260672995983)
5. [**python作业**](https://eteams.cn/community/help/1974530895369194621)

**三、功能详细描述**

**1、分组设置**

+ 默认分组：进入数据开发后存在一个默认分组，不可以编辑、修改、添加下级分组，系统管理员可以批量设置权限

  ![](https://dl.eteams.cn/site/b3e1eaaa-c900-4aeb-a72a-d162e36c88d2?imageType=png)
+ 新增分组：点击新增分组按钮可以新建一个一级分组，

  弹窗需要填写分组名称，同一级的分组，名称不能相同

  ![](https://dl.eteams.cn/site/271ee0f6-ab99-4d55-9e09-bdc095a65ab7?imageType=png)

  可以创建多级分组，每个分组可以点击对应分组下的新增分组按钮新增下级分组

  ![](https://dl.eteams.cn/site/40cca140-3475-4261-b462-7b4cf8a86363?imageType=png)

  操作：新增分组、重命名、删除、批量设置权限

  ![](https://dl.eteams.cn/site/4613362f-e802-4ee8-9f1c-b9c121f8580c?imageType=png)

  新增分组：点击新增分组可以增加一个下级分组

  ![](https://dl.eteams.cn/site/bb6fd299-9694-4d56-84be-aecebed3735d?imageType=png)

  重命名：可以修改分组的名称，不能与同级分组名称相同

  ![](https://dl.eteams.cn/site/5633bbcd-de51-418f-911c-2ee619bfc922?imageType=png)

  删除：点击删除按钮可删除分组，并删除分组下的所有数据集，不可恢复

  ![](https://dl.eteams.cn/site/e6b8e740-d7d4-4c1b-8317-e583a046959a?imageType=png)

  批量设置权限：可以对该分组下所有数据集设置权限，只有系统管理员才有此操作权限

  ![](https://dl.eteams.cn/site/7bbea9fa-586d-409f-90dc-e10fe2b94408?imageType=png)
