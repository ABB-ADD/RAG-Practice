# 事项关联

事项关联组件可以选择到系统中的各种事项信息，在页面上统一展示关联到的各种事项，如流程、客户、产品、联系人等信息。

在设计器中左侧搜索“事项关联”，点击或长按可以将组件拖拽到页面画布中。

![](https://dl.eteams.cn/site/00142a19-a140-4178-9298-c9ce25f1e271?imageType=png)

右侧属性：

1、事项关联范围：可以选择需要前台展示或可以选择到的事项范围；

![](https://dl.eteams.cn/site/79441a82-0a31-4cbb-81e6-0d8ebd122739?imageType=png)

2、分类显示：前台选择的事项支持分类展示。点击设置图标后，可以进行分类设置。

（1）分类支持自定义新建，若该分类被禁用，则分类下的事项前台也不展示。

![](https://dl.eteams.cn/site/dfb0fbef-7dcc-4436-9ae4-365985ff9111?imageType=png)

（2）分类设置添加完成后，可对事项关联进行分组设置，可以将同类型事项归到一个分类下，便于用户选择

![](https://dl.eteams.cn/site/29113c5f-4538-4437-960a-01fa21e364c6?imageType=png)

3、平铺模式：启用后，支持将已选择范围内的事项关联平铺进行展示。

![](https://dl.eteams.cn/site/22ea4c1f-1c5a-4e11-96ac-22281941aee1?imageType=png)

（1）默认展开：启用后，卡片区域默认展开；反之则隐藏。

![](https://dl.eteams.cn/site/e1d437ff-5479-4d45-ac26-9bf6df865f80?imageType=png)

（2）每行列数：支持设置卡片区域每行显示几列，默认每行5列。

（3）启用搜索：启用后，事项关联上方出现搜索框，支持用户快速搜索事项。

![](https://dl.eteams.cn/site/988bc08a-dc55-4b7b-81ca-0f8d45b605cc?imageType=png)

4、保存方式：添加数据后的保存方式分为两种方式（即时保存、统一保存），用户可根据场景自定义选择；

（1）即时保存：当添加/删除数据后，操作后立刻生效。无需点击按钮，进行统一保存；

（2）**统一保存**：需要在表单设计器-源码或按钮动作事件中插入代码才可生效。生效后，点击“保存/提交”按钮或已绑定事件的按钮后，才对该字段的已选数据进行保存。

属性设置完成后，可以在前台页面中，可以点击放大镜数据进行添加选择。

![](https://dl.eteams.cn/site/e5a4d82f-ece8-4585-9df4-427bb427ea7a?imageType=png)

选择后该字段中会统一显示多个类别下已选的事项信息。

![](https://dl.eteams.cn/site/94fa0a19-620d-48a4-bfa5-8709f106cdbc?imageType=png)
