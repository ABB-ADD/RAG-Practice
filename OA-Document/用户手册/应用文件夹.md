# 应用文件夹

应用文件夹即应用的所属文件夹，可以将同类型或同一用户的应用分类存放，方便管理，文件夹支持不同的颜色标记。目前仅支持一级文件夹。

在应用中心下，通过右上角【新建文件夹】按钮可以添加文件夹，并标记颜色：

![](https://dl.eteams.cn/site/72c0a485-dd2c-4630-b71b-83fda557c5e3?imageType=gif "20220110111359_141.gif")

文件夹上会显示创建人、更新时间以及文件夹下的应用总数：
