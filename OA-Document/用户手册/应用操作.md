# 应用操作

针对于单个应用可执行的一些操作，如下：

**应用设计**
：点击进入应用设计页面

**应用预览**
：预览应用运行

**应用编辑**
：修改应用基本信息

**移动到**
：修改应用所属文件夹

**迁出**
：导出应用包

**操作日志**
：查看当前应用操作日志

**上传至云商店**
：可将当前应用上传至云商店

**删除**
：删除当前应用
