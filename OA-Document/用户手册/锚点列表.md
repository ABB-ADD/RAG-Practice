# 锚点列表

# 一、 **功能背景**

在内容密集的长页面中（如单页应用、产品详情页、分模块配置页），用户需要快速定位到特定内容区域而无需手动滚动。

# 二、 **功能价值**

锚点列表通过集中展示页面关键节点，实现

“一键跳转”的快捷导航功能，极大减少用户查找内容的时间成本。

# 三、 **功能详细说明**

1.

页面

/

基础组件

/

导航类点击锚点列表拖入页面，锚点列表组件默认在右下角悬浮，并自动生成一个锚点。

![](https://dl.eteams.cn/site/53326a75-6485-4603-9ff5-1f0d348bf39f?imageType=png)

2.

锚点列表支持悬浮设置，默认为悬浮状态，悬浮时支持锚点列表位置设置。关闭悬浮，锚点列表占位，需要手工调整位置。

![](https://dl.eteams.cn/site/1ff98214-965d-427d-b5cd-4a93f6b70af2?imageType=png)

3.

锚点列表支持收缩，启用收缩时，可配置默认收缩。默认收缩开启，打开页面时，锚点列表默认为收缩状态。

![](https://dl.eteams.cn/site/1437f28d-3285-4c2b-bc04-ac508899d774?imageType=png)

4.

锚点列表允许用户拖动。

5.

锚点列表支持滚动距离设置，即可设置某个模块滚动时，距离浏览器顶部的间距。

6.

锚点设置，单击事件支持滚动到组件、自定义动作和回到顶部。
![](https://dl.eteams.cn/site/1082bc3a-04da-40f0-acfc-4d72cdb6abc9?imageType=png)

7.

锚点列表，滚动到组件，支持随意选择组件进行设置。

![](https://dl.eteams.cn/site/9b0658a7-175a-40a9-8a19-5f4b69b32fa1?imageType=png)

8.

点击锚点，滚动到对应的组件。

![](https://dl.eteams.cn/site/68cde6c2-f494-4bb7-9a32-a27726772281?imageType=png)
9.
锚点列表支持自定义样式配置。

![](https://dl.eteams.cn/site/a71789af-7917-4ab3-ad93-8b72e6d7954c?imageType=png)
