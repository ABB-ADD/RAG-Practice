# 考勤

【考勤】是在页面中显示考勤功能的组件，可以通过考勤组件进行签到和签退。

![](https://dl.eteams.cn/site/efef6425-834e-4d39-a397-d09be0e207e3?imageType=png)

通过拖动的方式将组件添加到设计器中：

![](https://dl.eteams.cn/site/d89139ae-f215-4b70-8ae3-81fc83cb7037?imageType=png)

考勤按钮会根据考勤模块的考勤状态来显示，未签到时按钮显示为“签到”，签到后按钮显示为“签退”：

![](https://dl.eteams.cn/site/d7300ae2-5dda-4cc0-a106-6155e3d9cd07?imageType=png)

考勤组件属性：

1、显示设置：支持设置考勤组件中的显示字段：日期、时间、地理位置（仅移动端）

![](https://dl.eteams.cn/site/8df9b7d7-8389-4b51-a87c-3f3fa8a41269?imageType=png)

2、日期设置：当显示字段勾选【日期】后，还可以设置日期字段的显示格式。共两种格式：跟随系统全局日期格式、指定日期格式

（1）若选择跟随全局日期格式时，系统将根据【个人设置】-【偏好设置】-【日期设置】中选择的格式进行显示；

![](https://dl.eteams.cn/site/f1fa7d2c-17ea-482b-8f09-b3958c656b03?imageType=png)

（2）若选择指定日期格式，则下方可以选择自己期望显示的日期格式；

![](https://dl.eteams.cn/site/92530a6a-a555-4b05-955c-9d8e02f9d5b0?imageType=png)

3、时间设置：
当显示字段勾选【时间】后，还可以设置时间字段的显示格式。共两种格式：时分秒、时分

![](https://dl.eteams.cn/site/ce738ad4-15c8-418a-bab6-9c8aacdda6b9?imageType=png)

考勤组件支持自定义样式：系统预置了默认的自定义样式，可供用户直接选择使用

![](https://dl.eteams.cn/site/e3c64d38-f240-4e7e-a38f-69a6ebe47ce1?imageType=png)

也支持启用自定义组件样式。启用后支持设置一些默认的样式信息。

![](https://dl.eteams.cn/site/245a0886-0e67-4c9b-9ed1-eae2103c84b6?imageType=png)

3、地址字体：
字体大小、字体颜色、是否加粗、是否斜体；

4、按钮背景色：签到/签退按钮的背景颜色；
