# 个性化设置

**一、概述**
  
个性化设置，用于设置列表的一些个性化设置，仅针对当前用户生效。

![](https://dl.eteams.cn/site/edcfcc21-ce7d-4eaa-a39d-8d5fd6bfbb43?imageType=png "20220715193939_623.png")

**二、功能描述**
  
个性化设置按钮默认开启，即在表格上默认可以使用；用户只要能查看列表便可使用个性化设置按钮，如下图所示：

![](https://dl.eteams.cn/site/f9be4dd9-9e16-4454-bc1c-c6450ac86ab0?imageType=png "20220715194139_149.png")

1、tab页显示：用于设置分类搜索是顶部下拉的展示样式还是平铺的展示样式，同时还可以设置显示哪些分类tab；

![](https://dl.eteams.cn/site/cc1f1437-ab19-4760-813f-27026567eaf0?imageType=png "20220715194335_86.png")

注：只有【表单】-【视图】-【搜索】-【分类搜索】中搜索字段方式显示设置设置了【平铺】的时候，列表上的个性化设置中才会显示【tab页显示】的功能

2、顶部按钮显示：用于配置列表顶部显示哪些操作按钮，如下图所示：

![](https://dl.eteams.cn/site/74894f55-2355-4b81-b034-b67daa74140d?imageType=png "20220715194902_898.png")

（1）列表右上角最多只能显示4个操作按钮，若开启的超过4个，则多出的不显示；

（2）按钮显示顺序可通过拖动进行排序；

（3）可点击【恢复默认】按钮，初始化到列表最初的样子

3、显示列定制：基于后台-显示列中设置的显示字段的基础上，用户可以设置具体显示哪些字段，如下图所示：

![](https://dl.eteams.cn/site/3324721a-c2e5-4dc8-8079-e4c543894ad1?imageType=png "20220715195324_719.png")

（1）可通过拖拽字段设置字段的显示顺序

（2）可点击【恢复默认】按钮，初始化到显示列最初的样子

4、表头操作样式设置：表头操作样式在【个性化设置】的【其他设置】中，目前支持控制排序的操作样式，支持将可编辑列表的排序更改为下拉样式。（
当前仅有可编辑列表支持表头操作样式设置
）
