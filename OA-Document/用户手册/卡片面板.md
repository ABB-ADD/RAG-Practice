# 卡片面板

**卡片面板卡片面板组件是一种快捷导航样式的交互卡片**；可通过简单的配置设计出放在页面上的导航卡片

![](https://dl.eteams.cn/site/ed6a58b5-a3ed-4e27-8cc1-5566cace46c1?imageType=png)

一、**添加菜单在组件属性设置中点击**【添加菜单】按钮，打开菜单设置弹窗，可添加需要链接跳转到的系统页面或系统菜单；

可设置菜单的显示图标、标题内容、描述信息、链接文案（超链接的文案）、链接地址、参数、链接的打开方式。

设置完成后点击确定，即可保存当前的设置。

![](https://dl.eteams.cn/site/5f03f479-5b79-45e9-a79c-c860977b05ae?imageType=png)

二、**属性设置如下图所示**，可进行以下几项设置，即可实现组件的基本使用效果。

![](https://dl.eteams.cn/site/692cd11a-11fe-4be4-89ee-405f11022d34?imageType=png)

* 基础设置

1、模式：设置显示的模式是卡片式显示还是列表式显示；

2、每行列数：选择“卡片式’显示时，可设置卡片每行显示几列；

3、背景：可设置背景为填充色的效果或者显示为背景图片；

4、背景效果：若选择固定，则背景色或者背景图片固定显示；若选择悬浮，则设置的背景会在鼠标悬停卡片式面板/列表式面板上时显示出来；

* **菜单设置此处对应的**【添加菜单】的设置，所添加的菜单会在此处依序显示，并可编辑或删除。
