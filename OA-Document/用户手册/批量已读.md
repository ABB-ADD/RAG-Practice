# 批量已读

一、**概述批量已读**，指可以对未读数据，批量进行已读操作。

![](https://dl.eteams.cn/site/d451d9e5-2a3e-4820-92dd-963ad0b2a72e?imageType=png "20220831134959_664.png")

二、**功能描述批量已读按钮默认不显示在按钮**tab页中，只有表单下的任一视图开启未读、反馈标识后，批量已读按钮才会显示并且按钮默认开启。

1、入口：需要先在 e-Builder后台管理-表单-表格视图-基础设置中开启开关，开启后，按钮tab页中才会显示批量已读按钮，如下图所示：

![](https://dl.eteams.cn/site/2d0c62e2-306b-42a7-a097-994a319b6039?imageType=png "20220831140140_133.png")

说明：按钮的显示位置仅支持设置右上角、右上角批量操作、右上角更多，默认选中右上角批量操作。

2、在表格列表中点击批量新已读按钮可弹出批量新已读的页面，勾选数据点击确认后，可将数据状态置为已读，如下图所示

![](https://dl.eteams.cn/site/25893074-0a97-4f67-ba14-ce727a7a7cca?imageType=png "20220831140605_133.png")
