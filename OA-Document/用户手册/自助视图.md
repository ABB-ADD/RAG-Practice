# 自助视图

**一、功能背景**

当前业务人员获取数据需依赖SQL技能，导致数据使用门槛高、效率低下。企业需一种自助式数据获取方案，降低技术门槛，提升数据利用率，提供数据集合血缘关系，客户可自行搭建模型创建数据集合
。

**二、功能价值**

自助视图的核心价值在于简化数据操作、
降低技术门槛、
提升效率、增强安全性和统一数据管理

**三、功能概述**

自助视图是一个基于建模构建SQL查询结果的虚拟表。它不存储实际数据，而是存储查询定义

**四、功能详细说明**

* 进入数据加工模块，选中数据准备tab，点击任意分组，右侧顶部出现新建按钮，默认为自助视图，点击可以进入自助视图新建页面

**2、自助视图总览**

* 1：视图名称输入框，该数据集合的名称
* 2：数据连接选择框，选择指定的连接，根据指定连接操作建模，建模之后构建的SQL也在该连接内执行。
* 3：源节点，建模的源节点，可以选择物理表、视图、SQL视图等数据。
* 4：流程节点。包含左右连接、上下连接、分组汇总、字段过滤、字段设置、新增列、排序的节点操作。
* 5：下个节点操作符，点击展开下一个节点类型选择按钮。
* 6：页脚，包含保存、预览操作按钮
* 7：操作节点按钮
* 8：源节点数据弹窗

**3、视图节点**

* 自助视图节点包含源节点以及操作节点，所有节点按照一定的顺序连接组合之后构建模型，构成数据集。

+ 源节点：选择数据源节点，建模从当前节点选中的数据开始。可选系统数据集、连接原始表、视图等作为源节点。

  ![](https://dl.eteams.cn/site/9f82be4b-44a3-4683-acc6-09b465456417?imageType=png)
  ![](https://dl.eteams.cn/site/af8a901a-c466-465b-be8f-e3120634e568?imageType=png)
+ 左右连接（操作节点）：选中左右连接节点后，需再选一个关联源节点后，在配置连接节点，连接方式存在左连接、右连接、内连接，并且需要关联连接表字段配置。

  ![](https://dl.eteams.cn/site/79d5ab1f-c196-4b7a-97ec-2ea319807252?imageType=png)
  ![](https://dl.eteams.cn/site/e45bedaa-b209-45e5-9e19-d1c29f677f15?imageType=png)

  ![](https://dl.eteams.cn/site/a0ffc0ff-82f3-4d42-89ef-b418b996dded?imageType=png)
  ![](https://dl.eteams.cn/site/ed0d6674-75ba-454d-9a31-efd0586535dd?imageType=png)
+ 分组汇总
  （操作节点）：在选中分组汇总后，需配置分组字段，汇总字段以及汇总方式等等。根据字段类型的不同，汇总的方式不同。

  ![](https://dl.eteams.cn/site/bc7319d9-92b7-4ac0-8fa1-bea3f5af28b3?imageType=png)

分组字段：可以选择字段进行分组。

![](https://dl.eteams.cn/site/5f9d7ad2-67e5-49f2-a759-c5e841971359?imageType=png)
![](https://dl.eteams.cn/site/bb9e4d84-b001-47e0-8cfb-2f147a590d9b?imageType=png)

数值类型的字段进行汇总，汇总的方式包含记录个数（记录分组后的总条数）、去重计数（分组后并且去重后的总条数）、求和（该字段求和）、最大值（分组后该字段的最大值）、最小值
（分组后该字段的最小值）
、平均
（分组后该字段的平均值）

  ![](https://dl.eteams.cn/site/54124d72-80f2-40c3-94c9-2c670a751115?imageType=png)
* 模型视图：展示模型节点、可预览SQL执行结果

  ![](https://dl.eteams.cn/site/d8771f50-8c4c-4058-a618-9a76e343c806?imageType=png)

  ![](https://dl.eteams.cn/site/505574ae-896c-4507-a33f-a14625b16c0f?imageType=png)
* 血缘关系

+ 来源表：该自助视图由哪一些源节点构成
+ 子孙表/仪表板：数据源调用记录。页面、报表、表单等引用关系

  ![](https://dl.eteams.cn/site/d2a1ba13-aa40-4f9b-abc0-d470c91c4d92?imageType=png)

* 使用/维护权限：用于设置数据集的使用、编辑权限

+ 默认：系统管理员默认拥有该租户下的所有数据集的维护权限；数据集创建人默认拥有自己创建的数据集的维护权限
+ 维护权限：可以对数据集的操作：查看、编辑、删除、移动分组、重命名、开启关闭缓存、给他人分配权限
+ 使用权限：拥有使用权限只可以查看此数据集，不可编辑数据集，
  [操作按钮](https://eteams.cn/community/help/1974669270042995986#%E6%93%8D%E4%BD%9C%E6%8C%89%E9%92%AE)
  隐藏，可以在数据源中被选中使用
+ 具体配置：使用、维护权限配置方式都是一样的

  鼠标放在选择人员处，可以选择分配权限的对象，可以对人员、部门、分部、角色、岗位、所有人设置权限，选择好对象后会自动保存，直接生效

  ![](https://dl.eteams.cn/site/a3e825ff-e846-4eac-a9b7-3f15347a3c8d?imageType=png)

  若想要删除权限，直接点击x即可，会自动保存

  ![](https://dl.eteams.cn/site/30e05215-ecc7-42ca-922e-52594dc1172c?imageType=png)

  自助
