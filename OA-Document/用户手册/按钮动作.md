# 按钮动作

按钮动作即为点击按钮时触发的操作，共有8种动作类型，分别为打开页面、触发动作流、自定义接口、回复评论、确认对话框、JavaScript、编辑字段值、查看日志。

打开页面可以选择打开某个页面地址，也可以选择读取字段作为链接地址或直接打开菜单；触发动作流需要在【应用->设置->动作流】中添加，添加完成后会在按钮中自动绑定；自定义接口即在系统中放入接口文件，在动作中配置接口路径后，点击按钮可以执行接口动作；回复评论即点击按钮可以打开回复评论页面；确认对话框即点击按钮打开弹窗，弹窗中可以进行二次确认操作；JavaScript即在设置中输入JavaScript代码，并在点击按钮的时候运行代码；编辑字段值可以对批量更改字段值动作进行预设与自定义，例如限制可以更改的字段、固定更改的值等，也可以全部允许用户自定义；查看日志
即点击按钮可以打开表单日志页面
。

**打开页面如想要在采购合同页面查看合同风险**，则可在按钮中配置打开页面

1、 按钮配置规则为打开页面，选中【合同风险】列表，如下图所示：

![](https://dl.eteams.cn/site/a1365c02-caf0-47f5-bbe7-4a3ce8c91de3 "20211206184221_428.png")

2、 配置完成后，打开前端页面查看前端显示效果

![](https://dl.eteams.cn/site/4194db65-6e35-448d-9cd9-7cd0a4b8cffb?imgType=gif "20210926190732_31.gif")

**触发动作流如想要给**offer已确定的用户办理新用户入职手续，则可在按钮中配置动作流在新用户入职表单中插入一条数据。

1、 在动作流中配置动作流，动作选择触发事件为【e-Builder->点击按钮】，应用选择【招聘管理】、表单选择【offer管理】、选择触发按钮【保存（编辑保存）】，触发类型为一次触发；

选择要执行的操作【e-Builder->新增表单数据】,应用选择【招聘管理】、表单选择【新入职员工】、操作人选择【动态赋值-创建者】、新增方式选择【新增数据】，最后在设置中设置字段对应，如下图所示：

![](https://dl.eteams.cn/site/c4cd5bea-226d-4abd-a10c-7602e314b6d2?imageType=png "20220509150725_555.png")

2、在动作流中配置完动作后，会在触发动作的按钮自动新增一条动作，如下图所示：

![](https://dl.eteams.cn/site/39295c21-11c4-46d5-a678-74972d2d30d3?imageType=png "20220509150729_106.png")

3、配置完成后，打开前端页面可查看设置效果：

![](https://dl.eteams.cn/site/8e0a2b98-0819-4a58-bb37-b39f635527a8?imageType=png "20220509150733_195.png")

**自定义接口用户选择自定义接口动作后**，可以在点击按钮时执行自定义接口

![](https://dl.eteams.cn/site/ce772b29-a08f-4067-9834-21d9b1523718?imageType=png)

接口路径：接口的存放路径，**由此定位需要执行的接口参数**：执行时传递给接口，**仅支持固定值回复评论**

如想要在offer管理列表查看每条数据的回复评论页面，则可在按钮中配置打开回复评论页面 。回复评论动作只有配置在具体每条数据上时才生效。

1、 在按钮中新建【打开评论】按钮，动作选择【回复评论】，如下图页面所示：

![](https://dl.eteams.cn/site/92e8d21e-6871-44c1-9059-9154846c25b3?imageType=png "20220509152147_879.png")

2、配置完成后，在前端页面点击按钮即可打开每条数据的回复评论页面：

![](https://dl.eteams.cn/site/be278c48-96fa-4784-bf84-b893967612d2?imageType=png "20220509152426_631.png")

注意：

（1）动作的执行按照动作的显示顺序来执行

（2）对于新建保存按钮、编辑保存以及保存并新建按钮来说，规则选择校验规则时，支持拖动此规则顺序至保存动作之前

（3）只有校验规则可以在保存动作之前执行，**其他规则均不可在保存动作之前确认对话框**

若按钮为点击执行高风险操作，往往需要在操作前进行二次确认，以免误操作，此时可以在执行按钮动作前配置确认对话框。点击确定时，成功执行后续动作：

![](https://dl.eteams.cn/site/8a14daa2-c4cf-4ad4-a5fe-22b6526bffdf?imageType=png)

点击取消时，后续操作不执行：

![](https://dl.eteams.cn/site/9d09b85c-530c-453f-a7cb-0b184dfb74a3?imageType=png)

JavaScript

如想要在页面上执行一些难以配置的复杂动作，或用户已有相关功能历史开发记录，需要复用原代码以保持功能一致性，可以通过JavaSript编写JS脚本执行。可以点击JS API查看动作JS支持的方法示例。

![](https://dl.eteams.cn/site/df72c426-08a8-46f0-ad4a-0c29a3c1a5e7?imageType=png)

**编辑字段值如想要限制用户可批量修改字段值的字段或应对某些固化场景**，例如合同状态变更时，修改合同状态字段为固化场景，且用户必须也仅能修改合同状态字段，可以使用编辑字段值动作。若对系统提供的批量修改与批量更改字段值统一按钮有其他要求，比如两个按钮需要分别统计权限或单独记录操作日志，或者需要在批量更改字段值前后执行其他操作，也可以使用编辑字段值动作编排在一个自定义按钮中。

1、添加动作为【编辑字段值】

![](https://dl.eteams.cn/site/8cdb0009-1230-4228-b3f0-58ab6920fd49?imageType=png)

2、选择编辑方式。编辑方式支持选择预设内容与自定义。其中，自定义类似于批量编辑按钮中的批量更改字段值，允许用户在动作执行时指定修改的字段与字段值。预设内容为管理员指定修改字段与字段值，动作执行时用户无法修改字段，仅能修改字段值（需管理员设置字段为【用户自定义】）

![](https://dl.eteams.cn/site/9e7591c3-92de-499d-8fa4-d65a5ad3724d?imageType=png)

![](https://dl.eteams.cn/site/21b55dda-97be-4f27-a0a2-7eb706b0acfd?imageType=png)

3、前台勾选需要修改的数据后，点击配置好的自定义按钮，弹窗中将显示允许编辑的字段与字段值

![](https://dl.eteams.cn/site/6f449869-dcc1-4f9a-bf6f-9e13ffb60dfc?imageType=png)

赋值方式：

支持管理员限制批量修改字段值时，可用的赋值方式与别名，并支持调整显示顺序。设置对所有字段生效，字段仅显示启用的且字段类型支持的赋值方式。用户批量编辑字段时，名称将显示为别名。

![](https://dl.eteams.cn/site/06e2d6b6-b9cc-4383-873b-15fe37c5e395?imageType=png)

**查看日志**

如想要在除了表单布局以外的其他地方显示表单日志，或者使用按钮的权限控制日志的查看权限，则可以在按钮动作中配置查看日志。

1、按钮动作中添加【查看日志】

![](https://dl.eteams.cn/site/045564e9-0c5b-4f7f-95b4-0060208e9f92?imageType=png)

2、
配置完成后，在前端页面点击按钮即可打开每条数据的日志页面

![](https://dl.eteams.cn/site/ebeb179e-0c59-4f17-957d-db8e67aa3ff2?imageType=png)
