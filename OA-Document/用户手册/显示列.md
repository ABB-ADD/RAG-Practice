# 显示列

显示列即控制表格要显示哪些字段，将要显示的字段选中即可，可以拖动调整字段的显示顺序。

**PC端**

控制PC端表格列表的显示字段。

![](https://dl.eteams.cn/site/cc72dcb1-9156-46ed-b084-866896634496?imageType=png "20220314134002_229.png")

显示列中的字段除表单字段外，还会显示一些系统字段例如【创建者、创建时间、公共标签、我的标签、数据状态、数据读取状态、操作】等，如下图所示：

![](https://dl.eteams.cn/site/996d35e0-2847-4479-a1e4-95208c6e7c62?imageType=png "20220530145638_534.png")

【操作】字段：只有按钮的显示位置选择了当前列表并且为行上时，该字段才会显示，并且默认选中不可取消；

【数据状态】字段：用于显示数据是暂存数据还是正常数据，有两个类型分别为暂存和提交；

【数据读取状态】字段：用于显示数据是未读还是已读数据，有三个类型分别为 已读、未读和反馈。
