# 移动端文档列表的点击未读数据打开文档详情后将数据改为已读状态

**功能背景**

移动端通过当前页面打开列表详情事件返回后，会整体刷新页面，原页面的滚动位置无法记录。通过新的webview窗口打开后关闭，不刷新当前页面数据。这里客户既需要记录当前页面的滚动位置，又需要刷新列表的数据。

**功能描述**

移动端事件动作浮层方式打开详情页后，回刷组件数据。

**功能说明**

1、移动端事件动作为浮层方式打开详情返回上一页后，组件数据回刷
