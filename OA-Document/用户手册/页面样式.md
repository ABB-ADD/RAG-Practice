# 页面样式

**页面样式用于设置页面的整体样式选择页面主题**

支持选择系统内置主题或用户自定义主题，快读设置页面样式

1、选择系统主题，系统内置了黑和白两套主题

![](https://dl.eteams.cn/site/006694bc-231c-4e6e-bf32-d052d29d7c77?imageType=gif)

2、**自定义主题支持用户自定义主题**，可通过关联组件的样式或编写CSS代码设计主题样式

![](https://dl.eteams.cn/site/33bdadbb-b1a0-4fb2-b197-dabbfec2c5cc?imageType=gif)

**自定义页面样式**

开启了自定样式后，页面以自定义样式的属性为准

1、背景设置：背景色、背景图片

2、动态背景：支持设置多图动态或多视频动态

![](https://dl.eteams.cn/site/2886119c-7093-4e66-b111-ae2cea9050de?imageType=png)

3、设置页面的宽度

4、设置页面的高度

5、设置页面的内边距

6、设置页面的外边距
