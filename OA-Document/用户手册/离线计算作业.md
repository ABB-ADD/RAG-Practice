# 离线计算作业

#### 一、 **功能背景**

为满足专业客户对数据自主管理的需求，系统将开放数据仓库的指定连接权限，允许客户在受控环境下自主执行DDL、DML操作及存储过程管理，同时通过严格的细粒度权限控制、完备的操作日志审计（记录操作人、时间、SQL语句等全链路信息）以及风险防控机制，在提升客户数据操作灵活性与效率的同时，确保符合金融等行业的合规性要求，并保障系统安全性。该功能主要面向具备数据库专业能力的客户群体，通过权限审批、操作复核等管理措施实现风险可控的自主数据管理。

#### 二、功能价值

1. 提升客户自主权，赋予专业客户直接操作数据库的能力，支持自主完成数据结构调整和数据处理

2. 增强业务敏捷性，支持快速实施数据模型迭代，缩短从需求提出到实现的周期。

3. 优化服务成本，降低简单数据库操作的运维人力投入。

4. 完整操作日志满足等保和行业合规要求。

#### 三、功能概述

1. 客户自定义执行DML、DDL、存储过程的创建调用语句

2. 允许动作流、定时调度触发执行离线计算作业。

#### 五、功能详细说明

1、**离线计算新建入口进入数据加工模块**，选中数据开发tab，点击任意分组，右侧顶部出现新建按钮，默认为
新建ETL
，点击箭头展示各功能新建入口，选择新建离线计算作业按钮，点击可以进入
离线计算作业
新建页面

![](https://dl.eteams.cn/site/0f0604d4-b0ce-417d-967c-f52d5d951a7e?imageType=png)

2、**离线计算作业总览下图所示**，1号输入框，需编辑离线计算作业名称。2号输入框编写执行SQL脚本。3号选择框选择脚本需要再哪一个指定的数据连接内执行。4号配置框，需要根据2号框中的SQL，解析获取占位符配置。允许其他模块或者定时调度传入不定占位符入参，达到执行动态SQL的作用。 当点击预览时。弹出5号框。预览查询列表数据。

![](https://dl.eteams.cn/site/635c8502-95e0-4413-87d0-12be3a9d3f99?imageType=png)

3、离线计算作业新建保存

* 新建离线计算作业必须要填写的点：

+ 数据连接
+ SQL语句
+ 离线计算作业名称
+ 字段设置需根据SQL刷新占位符配置

* 注意：

+ 离线计算作业的名称，在同一个分组下，数据集的名称不能相同，若填写了相同的名称后保存，toast提示名称不能相同

![](https://dl.eteams.cn/site/38d46a8b-2e83-4117-a1e4-65073338fc31?imageType=png)

+ 离线计算作业保存时，需要编辑离线计算作业名称、SQL、数据连接。若未选择或者填写时，保存时会直接报错。

![](https://dl.eteams.cn/site/7c11dfad-8fdf-425e-bb9b-6a2e419c4ee7?imageType=png)

+ 离线计算作业保存时，需要右侧的占位符配置需要保持最新，若不是最新在运行、保存时会给出提示。

![](https://dl.eteams.cn/site/7fb241d7-2576-4a43-98f7-41fa1cd20ace?imageType=png)

**5、离线计算作业卡片**

* 点击离线计算作业数据集，会进入离线计算卡片页

![](https://dl.eteams.cn/site/51489b09-e6d4-4ded-8d2c-2400f628f3d4?imageType=png)

* 模型视图：展示SQL语句、字段设置信息、SQL执行记录等

  字段设置信息只能查看，若需要修改需要点击编辑按钮进入编辑页

![](https://dl.eteams.cn/site/51489b09-e6d4-4ded-8d2c-2400f628f3d4?imageType=png)

* 使用/维护权限：用于设置数据集的使用、编辑权限

+ 默认：系统管理员默认拥有该租户下的所有数据集的维护权限；数据集创建人默认拥有自己创建的数据集的维护权限
+ 维护权限：可以对数据集的操作：查看、编辑、删除、移动分组、重命名、开启关闭缓存、给他人分配权限
+ 使用权限：拥有使用权限只可以查看此数据集，不可编辑数据集，
  [操作按钮](https://eteams.cn/community/help/1974669270042995986#%E6%93%8D%E4%BD%9C%E6%8C%89%E9%92%AE)
  隐藏，可以在DML中选中使用
+ 具体配置：使用、维护权限配置方式都是一样的

  鼠标放在选择人员处，可以选择分配权限的对象，可以对人员、部门、分部、角色、岗位、所有人设置权限，选择好对象后会自动保存，直接生效

![](https://dl.eteams.cn/site/d6ef920e-5795-4c36-b564-8b317b69ad80?imageType=png)

+ 若想要删除权限，直接点击x即可，会自动保存

![](https://dl.eteams.cn/site/a7554135-8570-4d7a-8558-8a0087c62044?imageType=png)

* 操作日志

+ 总览：操作日志展示对数据集进行的各种操作信息

![](https://dl.eteams.cn/site/071cc680-5d15-431d-812d-2d696ed951c0?imageType=png)
