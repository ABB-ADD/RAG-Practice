# 示例1--列表类报表

在大多数报表中列表类报表比较常见。比如客户列表，商品列表，合同列表等。

示例效果：(
**点击查看**
：
[相关视频介绍](https://live.vhall.com/room/watch/699161763? "相关视频")
)

![](https://dl.eteams.cn/site/a9cc171b-e14c-4135-94a8-9226a342150c)

在【应用中心】->【合同应用】->【报表】菜单下，创建报表“合同列表”：

![](https://dl.eteams.cn/site/85c8fcd4-1b0c-4acd-9dce-d1fd39e8121b)

直接点击卡片或卡片右上角更多【编辑】，进入报表设计页面。

第一步：添加数据源，即当前报表的数据来源，本次报表示例的数据来源为系统创建的自定义表单：“采购合同台账”中的数据。

![](https://dl.eteams.cn/site/1cc014b8-ff59-45de-9285-3e9499cca863)

第二步：在报表设计器中，设计好合同情况报表显示的字段显示名及标题。

![](https://dl.eteams.cn/site/d09def6d-743b-4c28-8e7c-988b12befb9d)

第三步：将左边的字段以拖拽的方式，添加在报表设计区域预留的单元格中。

![](https://dl.eteams.cn/site/db6bad63-7920-496b-a9a8-75f6f55b398d)

第四步：设置数据的扩展方向，从示例效果可以看出，报表展示是需要数据纵向排列的方式，所以设置的扩展方向为纵向，显示方式为：排列。

![](https://dl.eteams.cn/site/80b955c9-4afc-4f17-92f8-927f046a96a0)

说明：可以按住ctrl键，依次选中需要设置的字段，进行批量设置。

第五步：给需要进行计算的单元格添加公式，直接在单元格中输入=公式内容即可。

![](https://dl.eteams.cn/site/f72bcfb0-f5ad-4865-94c6-09645d9745d9)

第六步：设置数据的左父格和上父格。从示例效果来看，数据只需要设置左父格即可实现效果。

![](https://dl.eteams.cn/site/1a06e73f-bd13-4fa7-851f-04f7adccf76b)

说明：

1、一次选中多个单元格批量设置父格时，设置完了之后可以单个点击下查看是否都已经设置上了。

2、列表类报表如果不存在汇总统计，除第一个字段外，其他所有字段的左父格均可以批量设置为默认值来实现。

第七步：报表样式及单元格格式调整。

![](https://dl.eteams.cn/site/15aa7a01-6b0e-4b88-856d-b31e916e82b6)

以上已完成了列表类报表的设计过程。
