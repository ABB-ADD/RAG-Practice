# 表单视图配置

**一、概述**

表单视图，可设置卡片页面的显示样式、排版以及显示字段等，设置之后表单新建、编辑、显示页面都共用一套。可设置多个布局绑定不同的权限使用。表单视图支持两种布局——表单布局与页面布局，均支持分别设置PC端与移动端布局。

![](https://dl.eteams.cn/site/59a02ce7-a9f5-417d-b519-9b5a00d3feb9?imageType=png)

![](https://dl.eteams.cn/site/a41d52b1-cd40-4ebd-ac32-a136795d1bb3?imageType=png)

**二、功能说明**

**表单布局**

1、视图设置

![](https://dl.eteams.cn/site/ab421061-6625-455f-8166-754e1c1337cb?imageType=png)

（1）点击视图到卡片表单设计器页面，如下图

![](https://dl.eteams.cn/site/fd12775d-bea1-4369-b266-c5d3b11e9b22?imageType=png)

（2）重命名：给表单视图命名

（3）查看引用：可看到布局在哪些权限中被引用

![](https://dl.eteams.cn/site/1d5181da-bd17-4311-8257-f8b9f2fa24b0?imageType=png "20220314175911_391.png")

2、**默认布局可以给不同的布局设为不同类别的默认布局**，分别可以设为全部布局、新建布局、显示布局和编辑布局（默认选择为默认布局）。

其中需要注意布局显示的优先级：权限关联的布局优先级高于自定义默认布局高于系统默认布局）（标签显示会根据上述默认布局的优先级进行展示）

![](https://dl.eteams.cn/site/069dc7d0-5db5-4763-a4a2-bb3da48a788f?imageType=png)

3、**页面地址显示每个布局新建**、编辑、显示场景下的二级菜单地址，其中“$dataid$”表示用数据ID替换此部分

![](https://dl.eteams.cn/site/02a133b0-43ce-4b39-9bcf-2467c38e6833?imageType=png)

![](https://dl.eteams.cn/site/ef7a5574-62fc-4aa7-bb97-32e3831f0d8a?imageType=png)

**页面布局**

页面布局与表单布局不同，其是在页面设计器中进行设计，新建页面布局之后，点击进入的是页面设计器界面。与表单布局相比，页面布局的优势在于可以将表单的字段和页面中的各类图表组件融合在一起，如下图所示，不仅可以填写字段信息，也能够查看数据看板：

![](https://dl.eteams.cn/site/1af96147-52bf-46f2-b72c-b6d06a3e2255?imageType=png)

由于页面布局中放入的表单字段，无法直接和实际的表单字段相对应，因此页面布局中会有中间表组件作为中间键，并且页面布局新建完成后，会自动生成两个动作流，使页面中的字段和表单字段相对应，进行数据的提交与查询。中间表的介绍可以
[点击链接](https://eteams.cn/community/help/1970540091705700953)
