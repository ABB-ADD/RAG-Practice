# 订单列表

订单列表是以列表形式将订单展示在页面中，可以根据需要显示订单数据。

![](https://dl.eteams.cn/site/713e1dad-09e1-4a0d-ad36-0341dad46c19?imageType=png)

**场景说明**

如需要在页面中展示订单列表，则可以将订单列表拖入页面，设置想要展示的字段在列表中展示。

![](https://dl.eteams.cn/site/3a609b7a-7353-4184-8646-bcfc242a7b58?imageType=png)

设置项说明：

1、列表样式：设置订单列表按照列表式或表格式显示；

2、显示字段：列表中的订单数据显示哪些字段；

3、数据过滤：支持设置按类型搜索或按条件搜索，设置后，列表中仅显示满足过滤条件的数据；

4、排序字段：设置列表中的数据依据哪些字段排序；

5、每页行数：订单数据每页显示多少行；

6、显示总数：在标题处显示当前列表的订单总数。
