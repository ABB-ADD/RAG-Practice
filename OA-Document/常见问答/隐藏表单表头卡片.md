# 隐藏表单表头卡片

**问题描述：**

表单详情卡片不展示表头部分

![](https://dl.eteams.cn/site/3043b1e5-5b74-446a-b02c-14e36ae6839e?imageType=png)

**解决方式：**

后台管理中心
-表单 →基础信息 → 自定义标题
→ 关闭“显示表单卡片标题”
![](https://dl.eteams.cn/site/31a2c314-9b01-447a-901d-602e85179b2c?imageType=png)
