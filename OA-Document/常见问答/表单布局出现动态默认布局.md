# 表单布局出现动态默认布局

**问题描述：**

后台配置的表单布局及表单样式，再前端不生效，且打开的布局并不是在后台创建的布局。如下图

![](https://dl.eteams.cn/site/0a60b171-c2cb-4528-87a2-b01f50b2996e?imageType=png)

![](https://dl.eteams.cn/site/bce1d49d-82ab-4eef-9edb-48208b86bb14?imageType=png)

前端点击设计表单，此时显示为
动态默认布局，
如下图

![](https://dl.eteams.cn/site/9e87f014-2de7-4a95-885b-60fc3c182c33?imageType=png)

**解决方式：**

应用后台管理→
表单视图
→ 打开“
表单布局
” →进入表单设计器，点击布局管理，查看
默认布局是否被删除

![](https://dl.eteams.cn/site/ccd1020d-a225-424f-9baa-9a248b642fba?imageType=png)

只需要将默认布局配置即可

![](https://dl.eteams.cn/site/c0190277-8754-4dc5-b2b7-bff48ef183c4?imageType=png)

![](https://dl.eteams.cn/site/7de27fa0-bc51-4a79-aabd-59d62cdff970?imageType=png)
