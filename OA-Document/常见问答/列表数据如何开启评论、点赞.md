# 列表数据如何开启评论、点赞

**问题描述：**

列表数据如何开启评论、点赞，例如在常见问答门户对常见问答进行评论、点赞

![](https://dl.eteams.cn/site/5c7fb6ab-9c5e-4810-81f9-28980715c5b6?imageType=gif)

**解决方法：**

1：表单启用点赞和踩，确保赞和踩按钮启用

![](https://dl.eteams.cn/site/7cbafae4-bd22-474b-9cfe-a3951b4b97ab?imageType=png)

2：表单添加自定义按钮，配置回复评论事件动作

![](https://dl.eteams.cn/site/d18d67de-3e37-4d10-81ab-d19f8f1553b5?imageType=png)

3：列表添加自定义文本，系统参数选择评论、赞、踩按钮

![](https://dl.eteams.cn/site/eeacbe08-a8b3-41d0-bcbc-35eda696294a?imageType=png)
