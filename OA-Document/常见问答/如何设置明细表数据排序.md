# 如何设置明细表数据排序

**问题描述：**

如何设置明细表数据排序？

**解决方案：**

只有
**自定义独立表**
支持明细表数据排序，**自定义共享表暂不支持表单显示布局上设置明细表排序**：选中明细表组件，点击排序设置图标，选择排序字段和升降序类型
![](https://dl.eteams.cn/site/64a41258-e5cb-4914-9a89-b8e2d23dcc29?imageType=png)
表格视图上设置明细数据排序：视图基础设置中启用
**按明细展示**
，设置排序，添加字段时可切换到明细表字段

![](https://dl.eteams.cn/site/88b959e1-b390-4735-80c0-093f136eea59?imageType=png)
