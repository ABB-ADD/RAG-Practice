# 如何根据数值判断下拉单选框的值

**问题描述：**

例如表单中有一个数字字段与一个下拉单选框字段，如何实现以下场景：

当数字为小于60时，下拉选项值为较差；

当数字为60-90时，下拉选项值为普通；

当数字大于90时，下拉选项值为优异

**解决方式：**
