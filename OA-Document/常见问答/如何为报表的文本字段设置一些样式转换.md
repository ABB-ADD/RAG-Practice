# 如何为报表的文本字段设置一些样式转换

**问题描述：**

报表展示信息时，如何设置一些样式转换，从而使报表内容变的更加丰富美观。

**解决方式：**

1.报表支持多种条件格式的转换，用户可以点击链接查看：
<https://eteams.cn/help/1966121965828897454>

![](https://dl.eteams.cn/site/9ff0f8b0-fcf2-44c1-9c15-a1820d33eb72?imageType=png)

2.单元格字段也支持转换设置，用户可以点击链接查看：
<https://eteams.cn/help/1966130714302897470>

![](https://dl.eteams.cn/site/3775eee1-91ce-468d-9f47-84778f1a7285?imageType=png)
