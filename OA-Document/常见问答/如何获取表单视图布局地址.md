# 如何获取表单视图布局地址

**问题描述：**

表单视图的布局具体地址如何获取，如：新建布局、编辑布局、显示布局

![](https://dl.eteams.cn/site/bb243234-e173-44d2-a6ef-13ed3d738499?imageType=png)

**解决方式：**

进入应用后台管理中心，选择表单视图，如图所示点击布局
右上角···
，即可获取布局地址

![](https://dl.eteams.cn/site/7f91ed17-59c6-4acf-a90f-f1ef9cfdb2f7?imageType=png)

![](https://dl.eteams.cn/site/6bd934d1-5726-4970-b9dd-bf4da011f7f1?imageType=png)
