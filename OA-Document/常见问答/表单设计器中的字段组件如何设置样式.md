# 表单设计器中的字段组件如何设置样式

**问题描述：**

在表单设计器中，我们如何对字段组件进行样式的设置，例如设置字段标题的字号、颜色等等。

![](https://dl.eteams.cn/site/b7738c88-4424-46bf-ad57-73a7899584b4?imageType=png)

**解决方式：**

该场景分为两类：**表单布局简易版与高级版在简易版表单布局中**，如果我们需要对所有字段进行统一的设置，例如设置所有字段的标题倾斜，我们可以点击空白处，对整体布局进行设置：

![](https://dl.eteams.cn/site/7fbafc29-0e89-4673-bf6e-50fb8111770a?imageType=png)

如果我们需要对单一字段进行设置，我们可以点击该字段，在右侧的操作栏中进行组件样式的设置：

![](https://dl.eteams.cn/site/80ee344b-e197-4ce2-b72c-2e9adb511921?imageType=png)

在高级版布局当中，我们不仅可以按照简易版的进行设置，还能够直接进行样式的设置：

![](https://dl.eteams.cn/site/e9dd5c85-26b8-424c-b5a4-a850bc42009d?imageType=png)
