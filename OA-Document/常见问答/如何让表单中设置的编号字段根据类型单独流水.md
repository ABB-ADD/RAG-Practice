# 如何让表单中设置的编号字段根据类型单独流水

### **问题描述在搭建合同申请流程相应的表单的时候**，增加了一个编号字段用来对数据进行编号，**但是编号字段无法实现按合同类型单独流水希望让编号根据不同的合同类型进行单独流水**

![](https://dl.eteams.cn/site/74d4b3f0-6a24-4a2b-8eb7-7032b38a03b4?imageType=png)

### **问题答案可以使用流程编号功能来实现此需求**，关键配置如下：

1. 在表单中增加一个单行文本字段（用于记录流程编号）

![](https://dl.eteams.cn/site/76004462-02c6-4ced-8b15-c7d17106f7c7?imageType=png)

2. 在该流程的高级设置-编号设置中将编号字段设置为，表单中的“合同编号”

![](https://dl.eteams.cn/site/9062697e-919f-412e-a574-1c13c89fa7fa?imageType=png)

3. 配置编号规则，将表单字段合同类型，勾选单独流水

![](https://dl.eteams.cn/site/d278359e-6d23-45af-8ee3-841bba65ef83?imageType=png)

4. 其他配置按需调整，即可实现编号按类型单独流水
