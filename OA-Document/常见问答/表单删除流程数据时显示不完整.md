# 表单删除流程数据时显示不完整

**问题描述：**

表单设有审批时，删除数据时选不到未审批完成的数据。

![](https://dl.eteams.cn/site/354241b3-24dd-4eeb-b86f-beb56ff55f99?imageType=png)

**解决方式：**

未审批完成的数据无法在表单中直接删除，需要开启流程监控，才可对流程进行干预或删除操作；

后台管理-流程-
右上角打开“流程设置”
-添加一个监控类型-添加监控设置并保存-返回前台新建菜单-选择
流程监控
