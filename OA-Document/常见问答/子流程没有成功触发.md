# 子流程没有成功触发

### **问题描述在主流程的节点上**，设置了出发子流程，但到达主流程的该节点试，子流程却并未按期望触发

![](https://dl.eteams.cn/site/64190a31-c021-4f7d-b312-a7b96f9a6163?imageType=png)

### 常见原因

1. 子流程没有启用

![](https://dl.eteams.cn/site/c96e4ef5-54aa-4f9a-bf0c-42c54699e3e9?imageType=png)

2. 未获取到流程发起人

3. 触发条件不满足

![](https://dl.eteams.cn/site/1053dfd9-0f6f-4900-955f-f1c181b257b2?imageType=png)

4. **触发来源为空解决方案**：查看主流程的操作日志【创建子流程失败】的原因说明，根据具体原因调整重新触发

![](https://dl.eteams.cn/site/98ce303a-76c1-49a5-9a2f-75d746674b75?imageType=png)

5. 勾选的【每人员单独创建子流程】**的人力相关字段没有值解决方案**：检查后台勾选【每人员单独创建子流程】的字段值的填写情况

6. 触发节点、**触发时间不满足解决方案**：检查节点是否满足后台设置的触发节点，触发时间是否满足后台设置的到达节点、离开节点

7. **子流程为停用状态解决方案**：检查子流程后台【基础设置】-【工作流状态】是否为停用，如果为停用可改为启用或者重新设置子流程
