# 关联流程字段如何直接查看未参与的流程

**问题描述：**

例如在差旅费报销时，需要利用“关联流程”字段关联出差申请流程，方便财务人员查看出差情况，但是由于财务人员并没有参与出差申请流程，此时点击“关联流程”字段显示没有权限，需要申请，这种情况如何解决呢？

![](https://dl.eteams.cn/site/e7540c09-7ed9-4809-86ce-f28658899a04?imageType=gif)

**解决方式：**

为了使非流程参与人员可以点击“关联流程”字段查看流程详细信息，首先需要在权限管理中心-关联事项权限设置-开启关联事项权限传递：

![](https://dl.eteams.cn/site/68ff472b-d7ed-49e6-bc73-16a9e46ae6da?imageType=png)

之后在流程-设置-应用设置-基础设置中开始关联事项权限传递：

![](https://dl.eteams.cn/site/4551c0ac-373f-4708-abc7-f4df619925a6?imageType=png)
