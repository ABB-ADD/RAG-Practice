# 帮助提示组件如何联动其他组件使用

**问题描述：**

帮助提示组件如何联动其他组件使用，如日报统计情况鼠标悬浮提示帮助信息

**![](https://dl.eteams.cn/site/3dd06fa8-c3f6-4f05-8b31-9e1b7211fc7e?imageType=png)**

**解决方式：**

1：页面设计器添加容器组件，将环形图和帮助提示组件放到容器组件中

****![](https://dl.eteams.cn/site/d31afb6f-92e3-4900-bdb8-878470f44886?imageType=png)****

2：帮助提示通过属性维护提示内容，显示位置

![](https://dl.eteams.cn/site/7e106306-a1a7-4774-bfd3-7122a2cd5461?imageType=png)

3：帮助提示通过自定义样式选择绝对定位，定位布局选择left，通过间距功能实现位置对应

![](https://dl.eteams.cn/site/41a5857b-4c95-4d67-aa32-525f82654379?imageType=png)
