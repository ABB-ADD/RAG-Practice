# 关联字段开启多选后，如何计算选择的数量

**问题描述：**

如下图所示，表单中添加人员选择字段，并保持多选，如何用数字字段统计人员字段选了多少个人？

![](https://dl.eteams.cn/site/dbc2f471-48fb-496d-bff5-f33f8a28fba9?imageType=gif)

**解决方式：**

1.

在后台管理中心-表单引擎-函数列表里新建函数：

![](https://dl.eteams.cn/site/ee933dc6-3817-456b-becd-3bf97664ff2a?imageType=png)

函数如下：

function getOpIds(param){

if(param && param.optionContent){

return param.optionContent.split(",").length;

}

return 0;

}

2.

在表单中放入数字字段，设置函数公式，选择该函数：

![](https://dl.eteams.cn/site/d70e69ee-4d25-4d83-806e-f26101ecba32?imageType=png)
