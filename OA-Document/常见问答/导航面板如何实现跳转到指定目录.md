# 导航面板如何实现跳转到指定目录

**问题描述**

门户设计时，如何实现点击
导航面板组件菜单项
跳转到
指定目录

**解决方式**

1：菜单添加事件动作-
单击打开页面 ，链接地址为“选择菜单 “

![](https://dl.eteams.cn/site/4e5f1326-05d7-486a-a801-37b5a3d82461?imageType=png)

2：点击
放大镜
打开选择菜单页面，选择
知识中心
中任意文件夹后
确认

![](https://dl.eteams.cn/site/ecbcfa4d-05f3-4d99-a185-4bf09a063f4c?imageType=png)

3：打开方式选择新窗口，点击确定即可

![](https://dl.eteams.cn/site/b697e8de-7702-4f83-a8f8-2959848fb249?imageType=png)
