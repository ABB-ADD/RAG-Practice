# 设计器中表单字段已删除，表单前端还是可以选到

**问题描述：**

已从表单设计器中删除该字段，返回前台页面设置显示字段时，依然可以选到该字段。

![](https://dl.eteams.cn/site/e093fc19-d3e1-4373-8b1b-f92effdc4dc9?imageType=gif)

**解决方式：**

表单设计页面左侧字段区 → 选择“
已有字段
”→ 选择需要删除的字段(未从设计区删除的字段，在已有字段中灰色显示，表示当前不可删除)

![](https://dl.eteams.cn/site/ef2e89d1-8560-4dae-a758-776b46b4ad7a?imageType=gif)
