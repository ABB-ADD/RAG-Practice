# 页面组件：分段组件

# 1. **场景说明点击分段按钮时触发不同事件**，打开指定窗口、关闭当前窗口与刷新指定组件内容。其中刷新组件功能常用于移动端，如在任务台账中，通过点击按钮根据任务状态刷新台账信息。

展示效果如下：
![](https://dl.eteams.cn/site/b7c1745f-2648-43f9-b78c-85cc9f97edee?imageType=gif)

# 

# 2. **功能简介在页面设计器中**，拖入分段组件，通过数据项动作配置达到触发不同事件的目的。选择组件可选择本页面上的组件，类型暂限制为列表和图表。其中列表不包含业务列表。

# 

# 3. 操作说明

1

.在页面设计器中拖入分段
件与列表组件

。
![](https://dl.eteams.cn/site/2ee146ee-d95a-4b77-85f7-dec13edaf83c?imageType=png)

2

.选择分段组件，数据项中修改标题为未开始，点击动作按钮
。
![](https://dl.eteams.cn/site/38066e04-7f1c-43da-a3ee-dfd12bb4438b?imageType=png)

3

.设置"动作"为"刷新组件"，"选择组件"任务列表，"条件设置"中配置任务状态等于未开始
。
![](https://dl.eteams.cn/site/3f1252c0-0311-42e2-856d-6f052f2c3034?imageType=png)
![](https://dl.eteams.cn/site/13a0bb55-f3e6-4d27-8aed-4e51d5aa1293?imageType=png)
![](https://dl.eteams.cn/site/b1f077fe-8a8f-4d85-829a-4f419c3a29cf?imageType=png)
参考数据项"未开始"配置数据项"进行中"和"已完成"，配置完成运行效果如图所示：
![](https://dl.eteams.cn/site/dde780a1-eae6-414e-a882-71fd686f5d76?imageType=gif)

4

.选择分段组件配置打开表单动作
。
![](https://dl.eteams.cn/site/1c07fa5a-87ba-44d8-adbf-b20f3effe8bf?imageType=png)

设置"动作"为"打开页面"，"链接地址"
**选择指定表单页面也**
可以设置固定网址，"打开方式"选择新窗口

。
![](https://dl.eteams.cn/site/fb6a58be-6808-4a55-8b35-514390eab9c4?imageType=png)
![](https://dl.eteams.cn/site/8be1f5be-e1be-4cfa-9bcc-addc7987c4be?imageType=png)

配置完成运行效果如图所示：
![](https://dl.eteams.cn/site/216bdb1b-d939-4916-aefd-f738e7e98845?imageType=gif)

5

.配置关闭窗口动作
。
![](https://dl.eteams.cn/site/28f90bc6-0915-4180-91ad-9ee7942a8b38?imageType=png)

设置"动作"为"关闭窗口"

。
![](https://dl.eteams.cn/site/2cb58bd3-4c84-48db-be27-47214033cc53?imageType=png)

配置完成运行效果如图所示：
![](https://dl.eteams.cn/site/8e18bec8-2e04-492c-91f8-173878d3ce3c?imageType=gif)
