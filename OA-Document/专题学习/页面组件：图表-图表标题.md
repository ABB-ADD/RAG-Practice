# 页面组件：图表-图表标题

# 1. **场景说明图表维度为日期类型标题按钮年月日切换**。

展示效果如下：
![](https://dl.eteams.cn/site/a66b7cb4-a3e5-46ec-b2e8-15dc27ffa926?imageType=png)

# 

# 2. **功能简介上述场景需要在图表组件中打开标题设置选择文字按钮日期分组功能**

来实现

。

# 

# 3. 操作说明

1

.

**维度选择为日期类型的字段**。
![](https://dl.eteams.cn/site/9cd1f0ad-ee57-4d2c-bac8-54e532699114?imageType=png)

2

.点击开启组件标题

。
![](https://dl.eteams.cn/site/990036c1-3137-49f9-af6d-27492b948c62?imageType=png)

3

.开启标题后，点击配置操作按钮

。
![](https://dl.eteams.cn/site/8ca063ba-6d1f-4fd2-a65c-072b53b0f05c?imageType=png)

4

.在配置操作按钮页启用日期分组功能

。
![](https://dl.eteams.cn/site/6d2d4afe-06af-4d02-8041-5a5d11e6683d?imageType=png)

注意：

维度不是日期类型的字段时，没有此功能。
![](https://dl.eteams.cn/site/20aa027c-75c4-414c-a6a6-ccdbfce796b6?imageType=png)

5

.保存页面后运行查看配置效果

。
