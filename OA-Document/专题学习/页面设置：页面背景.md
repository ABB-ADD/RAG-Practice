# 页面设置：页面背景

# 1. **场景说明在页面设计中**，用户可以设置界面的背景颜色，通过调整颜色的不透明度，从而满足用户对于背景颜色的不同需求。

展示效果如下：
![](https://dl.eteams.cn/site/87391594-1afe-4e07-8845-31e00c6c6909?imageType=gif)

# 

# 2. **功能简介在页面设计器中**，点击空白处选中页面整体，在右侧栏样式中点击背景颜色，选择主体颜色后可通过对不透明度的调整获取到合适的颜色。

# 

# 3. 操作说明

1

.点击空白处选中页面整体

。
![](https://dl.eteams.cn/site/bf4d97ba-cc8d-4272-9129-c22401158eb6?imageType=png)

2

.在右侧栏样式中点击背景颜色

。

![](https://dl.eteams.cn/site/55570786-4b3b-45d0-9c39-b5730d1c4cc3?imageType=png)

3.通过对不透明度的调整获取到更多的颜色选择。
![](https://dl.eteams.cn/site/d5c74440-8b3d-4ddd-87e0-aa8a9f14a075?imageType=gif)
