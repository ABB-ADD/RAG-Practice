# 报表设置-查询条件

# 1. **场景说明报表支持添加查询条件**，可通过用户输入的条件来动态进行数据统计。
![](https://dl.eteams.cn/site/8b6e392d-8886-4557-8dc0-09c7afd6a39c?imageType=png)
![](https://dl.eteams.cn/site/b7a47e38-c621-4c38-bed6-12f19aa4e62a?imageType=png)

# 

# 2. **功能简介上述场景需要运用到添加查询条件功能**，通过在高级搜索/筛选处添加条件达到预期的效果。

# 

# 3. 操作说明

1.在报表设计器中，
设计
报表显示的字段显示名及标题，
将左边的字段以拖拽的方式，添加在报表设计区域预留的单元格中
。

![](https://dl.eteams.cn/site/410f3725-8aa1-4435-8ba4-26cfb727b460?imageType=png)

2.（1）设置数据的扩展方向，根据示例展示，数据的扩展方向为纵向扩展，显示方式为排列。（2）
设置数据的左父格和上父格，
从示例效果来看，数据只需要设置左父格即可实现效果，左父格均为
默认值（默认值即该单元格左侧相邻的第一个单元格）
。
![](https://dl.eteams.cn/site/0620ca01-993d-4da2-9d03-fc983f8ccde9?imageType=png)
说
明：可以按住ctrl键，依次选中需要设置的字段，进行批量设置。

3
.
报表样式及单元格格式调整。
![](https://dl.eteams.cn/site/45e0c674-a7e3-41e6-8e00-d55c622033a2?imageType=png)

4.点击高级搜索右侧的添加查询条件，进入添加查询条件设置页面。
![](https://dl.eteams.cn/site/6ac2d9c7-16a4-4a35-9030-60b8aa6a461d?imageType=png)
![](https://dl.eteams.cn/site/f58cec12-99c4-4a1f-879a-cf77f008c96e?imageType=png)

5.显示名称：合同名称，字段类型：文本，默认值类型：常规；查询条件中选择数据集采购合同台账，选择字段合同名称。
![](https://dl.eteams.cn/site/a94253bb-336d-46af-9279-9098c950cfbf?imageType=png)

6.保存后通过预览按钮预览效果：
![](https://dl.eteams.cn/site/a3a2076c-bb96-4c33-a008-92507e6fffe1?imageType=png)

点击右上角高级搜索图标打开条件查询，搜索框内输入合同名称进行数据查询。

![](https://dl.eteams.cn/site/47b00d4a-5079-4346-8baa-dbb1712d6605?imageType=png)

7.在高级搜索处点击下拉键选择筛选，
保存后通过预览按钮预览效果：
![](https://dl.eteams.cn/site/bd953bc5-80dc-496f-812f-5d3d0d3f5cca?imageType=png)
![](https://dl.eteams.cn/site/37aab8d8-797c-4049-95d6-9f957cb89474?imageType=png)

搜索框内输入合同名称进行数据查询。
![](https://dl.eteams.cn/site/d4de29f6-2d0b-4bf9-984e-abc390d1f73a?imageType=png)
