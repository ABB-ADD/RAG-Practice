# 报表功能-突显设置、进度条

# 1. 场景说明

①报表突显设置，②报表进度条设置
![](https://dl.eteams.cn/site/1c33bd06-573d-4b11-8ac9-7c3a687a77f5?imageType=png)

# 

# 2. 功能简介

①突显设置：设置字段突显条件，根据条件设置展示不同字段样式。

②进度条设置：通过条件格式开启数据条功能，以进度条形式展现字段数据。

# 

# 3. 操作说明

1.
报表突显设置：

（1）选中采购合同金额字段点击条件格式。
![](https://dl.eteams.cn/site/afa725b0-9ca7-4753-a754-59669399381b?imageType=png)
（2）进入设置条件格式页选择设置突出显示。
![](https://dl.eteams.cn/site/c2ffc97a-cbd6-4d33-a8ee-49417c54f100?imageType=png)
（3）设置突显条件，调整展示样式。
![](https://dl.eteams.cn/site/21be3333-1575-45eb-975a-cfdc3ec54206?imageType=png)
![](https://dl.eteams.cn/site/2e719bf1-3dcb-419e-858c-5516aa42d049?imageType=png)
保存并预览效果：
![](https://dl.eteams.cn/site/04ac2799-c8d5-4941-af66-e353a5359907?imageType=png)

2.
报表进度条设置：

（1）选中采购合同金额字段点击条件格式。
![](https://dl.eteams.cn/site/afa725b0-9ca7-4753-a754-59669399381b?imageType=png)
（2）进入设置条件格式页选择设置数据条。
![](https://dl.eteams.cn/site/6438841a-1d44-454d-a32b-c5e2ee8992c9?imageType=png)
（3）启用数据条配置条件样式。
![](https://dl.eteams.cn/site/d5ffd7d1-81d5-462f-a49f-fa75ff5ab1e4?imageType=png)
保存并预览效果：
![](https://dl.eteams.cn/site/abd09430-54c0-428d-a0e2-d2f5cc0703d9?imageType=png)
