# 勾选采购申请新建采购订单

# 1. **场景说明勾选采购申请数据**，新建相关采购订单信息。

![](https://dl.eteams.cn/site/e5a229d0-6e3c-4e5f-971b-6b59adb82a03?imageType=gif)

# 

# 2. **功能简介通过设置按钮动作**，配置添加参数，达到勾选采购申请数据，带入采购申请单新建视图的效果。

# 3. 操作说明

1.页面右上方点击进入后台管理。
![](https://dl.eteams.cn/site/745a65b3-2959-4554-9860-3f5dad32e0c2?imageType=png)

2.在按钮项创建新按钮"采购申请单转订单"，显示位置设置为表格视图右上角。

![](https://dl.eteams.cn/site/74765261-b6dc-4f4f-842b-44d5ad8dbe3b?imageType=png)

3.设置新建动作：添加新动作，链接地址选择"采购订单专题表单"的新建布局。
![](https://dl.eteams.cn/site/67f253b9-69e4-4f26-ac5a-fc47908db2ed?imageType=png)

4.点击参数配置右侧小齿轮，进入参数配置页面，设置添加参数：

![](https://dl.eteams.cn/site/8ba1a7eb-bab7-4a6a-9bf4-80b5a53f7354?imageType=png)

5

.启用"采购申请单转订单"按钮。

![](https://dl.eteams.cn/site/9016cb26-9fc5-4741-9b74-a497e594b003?imageType=png)

勾选多条数据时，唯一值的字段将不被带入，如采购申请日期。
