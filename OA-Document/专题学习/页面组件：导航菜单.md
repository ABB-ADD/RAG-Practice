# 页面组件：导航菜单

# 1. **场景说明导航栏目可以通过链接地址实现一键跳转到别的菜单**，比如页面，表单等。

展示效果如下：
![](https://dl.eteams.cn/site/9d49029d-5f6b-4214-9171-83cd7d8467e8?imageType=png)

# 

# 2. **功能简介上述场景需要通过设置导航菜单组件实现**，在导航菜单中，**点击右侧属性面板对**【导航项】进行编辑。
