# 报表功能-字段分值图标、斜向文字

# 1. 场景说明

①字段分值图标，②表头设置斜向文字
![](https://dl.eteams.cn/site/0eda0a81-d7df-4938-bdbb-102aa6bc6619?imageType=png)
![](https://dl.eteams.cn/site/c97313cb-5b0d-4d77-ae46-2716a6490f30?imageType=png)

# 

# 

# 2. 功能简介

①字段分值图标：

设置最大值标准，将数值类单元格按大小比例转换为星形组合。

②斜向文字

：单元格中插入斜线并将文本切分为若干个区域，实现斜向文字表头的效果。

# 

# 3. 操作说明

1.
字段分值图标：

（1）进入报表设计器点击数字字段课程分。
![](https://dl.eteams.cn/site/ec369b31-9969-4108-a99a-6983a2a1cc90?imageType=png)

（2）在右侧单元格栏中，点击转换区域的字段，并选择分值图标。
![](https://dl.eteams.cn/site/16efde17-79c0-4a10-b6fd-9fbacb40c8cc?imageType=png)
（3）输入分值图标的自定义最大值。
![](https://dl.eteams.cn/site/2d9b01b2-9d5e-43d6-85a2-ef8654eb6853?imageType=png)
保存并预览效果：
![](https://dl.eteams.cn/site/6152733a-f8f0-4fca-9c10-83bd9b3e3b16?imageType=png)

2.
报表设置隐藏列：

（1）选中图表的表头"星期节次"。
![](https://dl.eteams.cn/site/1f9b7ac7-91dd-4e10-88d0-5550b14af3d3?imageType=png)

（2）在右侧单元格栏中，点击转换区域的字段，并选择斜线文字。
![](https://dl.eteams.cn/site/407fd03c-5fbc-426e-9e08-28bc62af81eb?imageType=png)
**支持从左下至右上排布和从左上至右下排布注意**：

①生效对象：用半角分号分隔的若干个文本，如：姓名;年龄;职业。

②分隔文本内容的个数最多为3个，超出部分不显示。

③当单元格内容没有半角分号时，不呈现分隔效果。

④可通过调整单元格大小来适配分隔内容。

保存并预览效果：
![](https://dl.eteams.cn/site/09ec6422-19a8-4fcc-97ae-1d9f518a2e17?imageType=png)
