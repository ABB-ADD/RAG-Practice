# 页面组件：页头

# 1. **场景说明通常当我们预览门户首页或者模块看板的时候**，会想通过点击功能按钮快捷跳转数据表单或者流程发起界面，如在采购需求看板中通过点击按钮快捷进入采购需求/采购计划/采购合同表单页面或者新建页面。

效果如下图展示：
![](https://dl.eteams.cn/site/65de9a94-9a5f-4e29-862d-6525409772f8?imageType=gif)

# 

# 2. **功能简介上述场景通常使用导航面板控件实现**，本次将介绍另一个可以实现该场景的控件：页头控件，通过为页头配置按钮与相关事件实现点击按钮打开指定的页面

。

# 

# 3. 操作说明

1

.从组件栏中选择拖入一个页头控件。
![](https://dl.eteams.cn/site/aff4f8f7-3fd0-4223-8af5-3b596b93d28e?imageType=png)

2

.添加2个按钮，为按钮添加文字采购需求、采购计划并配置相应的图标。
![](https://dl.eteams.cn/site/7057e751-005e-4591-b193-7794967b9b14?imageType=png)

3.点击添加按钮事件配置，动作：打开页面，链接地址：采购需求/采购计划表格，打开方式：新窗口。
![](https://dl.eteams.cn/site/56460a19-33c9-42f6-bbbc-cf400aac9a79?imageType=png)
![](https://dl.eteams.cn/site/be2ee21c-c9e2-478b-8e81-b6041e9e92de?imageType=png)

4.新添加一个
新建合同
按钮，并将按钮拖动至
分割线
下方，配置事件动作打开采购合同的新建布局。
![](https://dl.eteams.cn/site/1a18d77f-bec4-4c20-8843-2d89a593ac10?imageType=png)
![](https://dl.eteams.cn/site/7c3961c5-29ab-487a-8cff-b810d4e4abad?imageType=png)

5.保存预览配置效果，点击页头控件右上角的更多键，可以查看拖动至
分割线
下方的
新建合同
按钮

。
![](https://dl.eteams.cn/site/d67cd2a0-45e3-49c2-8426-7f7e1072affb?imageType=png)

6.进行按钮的样式设置

。
![](https://dl.eteams.cn/site/b49ef006-bc33-40e5-825b-d0bde14625f4?imageType=gif)

7.根据用户使用情况还可以对按钮进行暂时隐藏，隐藏的按钮将不再进行展示，**如隐藏采购计划**

与
新建合同
。
![](https://dl.eteams.cn/site/58a97265-0cd2-4309-b34c-8d26f32d7b2a?imageType=png)
![](https://dl.eteams.cn/site/d8778738-2aab-4add-a98d-91b3493a3656?imageType=png)

显示
即可

。
