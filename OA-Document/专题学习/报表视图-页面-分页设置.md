# 报表视图-页面-分页设置

# 1. **场景说明当数据比较多时**，可以通过动态sheet页设置对报表进行分页。
![](https://dl.eteams.cn/site/f8564228-5266-40fb-ab98-c0365af8f47a?imageType=png)

# 

# 2. **功能简介上述场景需要运用到报表页面分页设置功能**，通过动态sheet页分页字段设置达到预期的效果。

# 

# 3. 操作说明

1.在报表设计器中，设计好报表显示的字段显示名及标题。

![](https://dl.eteams.cn/site/cf2e60a5-a11e-45a0-8240-499fd799597b?imageType=png)

2.将左边的字段以拖拽的方式，添加在报表设计区域预留的单元格中。
![](https://dl.eteams.cn/site/ffb6af4a-736d-4dae-ad46-2248defbb789?imageType=png)

3.设置数据的扩展方向，根据示例展示，数据的扩展方向为纵向扩展，客户名称与商机名称显示方式为分组，其他的数据为排列。
![](https://dl.eteams.cn/site/dab72f30-3941-4cd7-92bd-58d29b12062b?imageType=png)

说明：可以按住ctrl键，依次选中需要设置的字段，进行批量设置。

4.设置数据的左父格和上父格。从示例效果来看，数据只需要设置左父格即可实现效果，C6无需设置左父格，C8、F8左父格为C6，其他数据左父格均为默认值（默认值即该单元格左侧相邻的第一个单元格）。
![](https://dl.eteams.cn/site/7443becc-30d9-4f00-98a9-7adbd0484c0c?imageType=png)

5.页面分页设置中动态sheet页分页字段选择C6。
![](https://dl.eteams.cn/site/a528ff1e-99a9-4f03-a900-ef01f08c11fd?imageType=png)

6.报表样式及单元格格式调整。
![](https://dl.eteams.cn/site/6fb45c9a-e074-4e37-a248-e14b58a3e1d6?imageType=png)
