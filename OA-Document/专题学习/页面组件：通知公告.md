# 

# 2. **功能简介在页面设计器中**，拖入通知公告组件，配置数据源、显示字段，设置头部展示类型与内容轮播方式。

# 

# 3. 操作说明

1

.在页面设计器中拖入通知公告
组件

。
![](https://dl.eteams.cn/site/51a5117b-e0c3-4a5d-a156-2ddc1c63e937?imageType=png)

2.在右侧属性栏中选择数据源与显示字段。
![](https://dl.eteams.cn/site/2325e8d7-a693-4b47-b6e9-1c95fcaeb28d?imageType=png)

（1）添加数据源，即当前通知公告组件的数据来源。
![](https://dl.eteams.cn/site/c9596bc1-60dd-4e49-a8cb-f7a3ed195ead?imageType=png)

（2）设置显示字段。
![](https://dl.eteams.cn/site/45afc565-8df5-4e99-a7c2-f814b1e78eca?imageType=png)
设置完成后组件数据如下图所示：
![](https://dl.eteams.cn/site/1a01fcfc-6d1e-4720-a3d3-756355b463e3?imageType=gif)

3.数据过滤，点击设置过滤条件。
![](https://dl.eteams.cn/site/5c6cc209-0af7-479d-a843-066539dce976?imageType=gif)

4.根据数据源中字段对展示信息添加排序。
![](https://dl.eteams.cn/site/1a29dfa9-a2ff-4d90-8d35-c8672d0f4e54?imageType=png)
![](https://dl.eteams.cn/site/c6af80bc-ecc8-463b-be18-e30feb732669?imageType=png)

5.头部设置：

（1）图标类型，在头部内容处设置不同图标样式。
![](https://dl.eteams.cn/site/237e61f1-cafd-4f3b-9ffc-e280b452e3f0?imageType=gif)

（2）文字类型，在头部内容处设置文字信息。
![](https://dl.eteams.cn/site/0d6e83ec-d935-42ec-a2b8-1f5b14a72081?imageType=gif)

6.其他设置：

（1）公告条数，设置轮播展示的通告信息数量。
![](https://dl.eteams.cn/site/750abbc8-194b-453b-941c-5b96228c3f47?imageType=gif)

（2）轮播方式，可以设置上下滚动和左右切换两种轮播展示方式。
![](https://dl.eteams.cn/site/a8e999d4-102c-41a9-ab1f-2807b9f3ed0c?imageType=gif)
