# 报表功能-导出文件

# 1. **场景说明报表支持导出文件**，用户可以使用三种不同的形式导出报表数据。

![](https://dl.eteams.cn/site/d5f067db-3302-43da-8320-b1419d24761e?imageType=png)
导出PDF：

![](https://dl.eteams.cn/site/0d0ee05c-657c-4624-87fc-a68a5f71722b?imageType=png)

# 

# 2. **功能简介上述场景需要运用到报表运行页面的导出文件功能**，点击导出文件按钮可以使用三种不同的形式导出报表数据。

# 

# 3. 操作说明

1.在报表运行页面点击右上方的导出文件。
![](https://dl.eteams.cn/site/1193e8b3-fc48-4d17-bdf2-b75e80c00927?imageType=png)

2.选择导出形式并点击按钮。
![](https://dl.eteams.cn/site/afe74994-5c44-4dc2-9368-18148d265f4a?imageType=png)

3.选择下载文件的保存位置等待完成下载即可。
![](https://dl.eteams.cn/site/04930783-e99f-4caa-a5f4-9804b88785bb?imageType=png)
