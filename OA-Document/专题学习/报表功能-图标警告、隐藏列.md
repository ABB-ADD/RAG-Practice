# 报表功能-图标警告、隐藏列

# 1. 场景说明

①图标警告设置，②报表设置隐藏列
![](https://dl.eteams.cn/site/37f71f74-8903-4b36-a07a-37492e2af72f?imageType=png)

# 

# 2. 功能简介

①图标警告：设置条件格式页点击图标集，通过选择图标设置图标警告。

②隐藏列：

选中目标行/列，在表头区域点击右键，选择隐藏行/列，即可标记为隐藏区域

。

# 

# 3. 操作说明

1.
图标警告设置：

（1）选中采购合同金额字段点击条件格式。
![](https://dl.eteams.cn/site/5942f976-eaf7-479d-8be7-a1216d8f1270?imageType=png)
（2）进入设置条件格式页选择图标集。
![](https://dl.eteams.cn/site/bfdd4af7-4011-4315-b816-17191ec65da1?imageType=png)

（3）点击启用图标集并选择图标。
![](https://dl.eteams.cn/site/caf9cd7e-dc59-40e7-95c8-725110fd4e27?imageType=png)
保存并预览效果：
![](https://dl.eteams.cn/site/847c3a11-ca65-4969-a794-3689e3e5d507?imageType=png)
![](https://dl.eteams.cn/site/41d14c58-1c4e-434e-8354-81850a699953?imageType=png)

2.
报表设置隐藏列：

（1）选中合同状态列，在表头区域点击右键，选择隐藏列。
![](https://dl.eteams.cn/site/ad7c53d7-b10b-42de-b0fe-3109a3481cc4?imageType=png)
表头字母或数字文案上出现“[]”，即表示该区域将在预览界面隐藏。
![](https://dl.eteams.cn/site/c15b2e5b-076f-4b8f-90d4-d01a576209fd?imageType=png)
保存并预览效果：
![](https://dl.eteams.cn/site/f3aee855-7682-4399-8100-c294d3b82ef9?imageType=png)

（2）选中合同状态列，在表头区域点击右键，选择取消隐藏列。
![](https://dl.eteams.cn/site/330e5f90-286a-439b-863f-4c197f13c35f?imageType=png)
![](https://dl.eteams.cn/site/32e21852-7864-4a00-9de7-2854521e636d?imageType=png)
保存并预览效果：
![](https://dl.eteams.cn/site/d9303236-9ea5-4ef4-943c-93bc30951f14?imageType=png)
