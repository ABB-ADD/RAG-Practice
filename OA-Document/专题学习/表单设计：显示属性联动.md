# 表单设计：显示属性联动

# 1. **场景说明在**CRM工程营销中，录入跟进信息时若选择生成跟进计划，则显示并允许编辑计划信息，若不生成跟进计划，则
隐藏计划信息

。

生成跟进计划的跟进信息数据可以通过点击
“新增计划”
按钮，在跟进计划页面新增相关数据。展示效果如下：
![](https://dl.eteams.cn/site/4c1f751a-c5ad-4038-9a76-6ad93a681f4b?imageType=gif)

# 

# 2. **功能简介在表单设计器的显示属性联动页中**，设置触发条件
是否新建计划等于否
时，隐藏计划日期、计划内容信息；

配置
新增计划
按钮，设置条件
是否新建计划等于是
时显示，并通过动作流新增跟进计划表单数据
。

# 3. 操作说明

**1.配置显示属性联动**

（1）表单页右上方点击进入表单设计器。

![](https://dl.eteams.cn/site/023ae16a-3e23-44b7-9c75-65655e9185ea?imageType=png)

（2）点击表单设计器顶部按钮进入显示属性联动页。
![](https://dl.eteams.cn/site/83ac7939-6e1d-43d1-b011-f723b3d213e3?imageType=png)

（3）点击联动列表右上角
加号
或者
新建规则
按钮创建新的显示属性联动

。

小提示：

①红色字段的项表示已经不存在的项需要重新设置；

②主表触发字段能修改主表或明细字段的显示属性，明细表的触发字段能修改本行字段的显示属性及其他表（主表或其他明细表）显示属性；

● 隐藏：隐藏【变更的字段】的字段名称和字段控件，保留字段所在的区域及样式；

● 隐藏行：隐藏【变更的字段】所在的整行（隐藏行时，如行内其他单元格存在合并行的情况，有可能造成模板显示异常），只对高级版编辑器布局有效。

![](https://dl.eteams.cn/site/0cbffdb3-22ba-4b3d-baa2-d99ce7c5c37d?imageType=png)

（4）新建显示属性联动页生效范围模块中，生效维度可选择
当前表单
与
表单布局
。
![](https://dl.eteams.cn/site/cee91501-210d-4023-ac3a-cfb084f5ac05?imageType=png)
当生效维度为表单布局时，可以选择表单的默认布局或者新建的布局进行配置。
![](https://dl.eteams.cn/site/fe9b70d3-9838-4f47-ad66-82b506c07c24?imageType=png)

（5）设置触发条件，点击添加条件按钮，当
是否新建计划等于否
时，触发变更对象设置

。
![](https://dl.eteams.cn/site/aa65cb6c-f56e-488f-8160-a7887eecacbd?imageType=png)
![](https://dl.eteams.cn/site/826deb24-c14e-4cb5-ac5f-6e9dafdd0aef?imageType=png)

（6）点击变更对象设置项右侧加号新建变更信息，选择字段
计划日期
、
计划内容
，变更显示属性设置为
隐藏

。
![](https://dl.eteams.cn/site/b4653f45-324d-41d9-881f-fb77682d7abb?imageType=png)
![](https://dl.eteams.cn/site/03e6d240-ee3a-46c2-9097-875773a521c9?imageType=png)

配置效果
![](https://dl.eteams.cn/site/a068d89d-a7ce-4895-b4af-81039c7d2a7e?imageType=gif)

**2.配置新建计划按钮**

（1）按钮显示位置设置为行上，按钮权限模块点击编辑条件，条件设置为
是否新建计划等于是
，配置完成开启此按钮

。
![](https://dl.eteams.cn/site/74e7b55e-833b-4d2d-a21b-dc48f80f8d53?imageType=png)
配置效果
![](https://dl.eteams.cn/site/85a7ddcc-9859-4d63-8727-166db384a8cd?imageType=png)

**3.配置新建计划动作流**

（1）添加触发事件
点击按钮时
触发，选择按钮
新建计划
。
![](https://dl.eteams.cn/site/bf7dcad6-d266-4088-9d9a-a2c82de88f72?imageType=png)

（2）添加操作
新增表单数据

，设置表单数据

。
![](https://dl.eteams.cn/site/9f1b83f6-0758-4905-bd8a-662937f82e11?imageType=png)
