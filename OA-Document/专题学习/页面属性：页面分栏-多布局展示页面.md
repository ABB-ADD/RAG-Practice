# 页面属性：页面分栏-多布局展示页面

********1. 场景说明********

通常不同的业务场景下可能需要设置不同的页面布局，有些则需要左有两栏，也有些可能需要上下展示等。如下左右边栏布局。

效果展示如下：

![](https://dl.eteams.cn/site/88f50cc8-e1e8-4204-b4dc-e4fbf4a864a9?imageType=gif)

********2. 功能简介********

上述场景可以通过页面分栏功能实现，页面可选左边栏、右边栏、左中右、上边栏、下边栏，上中下布局。同时可以在样式面板设置布局的行列间距，当启用页面分栏功能时，还支持分栏滚动以及用户收缩等功能。

********3. 操作说明********

1. 点击页面设计器面板的空白处，选择布局，布局支持左右边栏，上下边栏 等布局可以选择。
![](https://dl.eteams.cn/site/4e66dca1-8610-44ed-a2ae-ca779d9168d1?imageType=png)

2. 在样式面板可以设置页面的行列间距。

![](https://dl.eteams.cn/site/a1df4caf-177c-403a-8fde-054d0c7e1188?imageType=png)

3. 可以设置分栏滚动，分栏滚动开启之后就可以实现页面分栏的滚动；可以各个分栏的列数。

![](https://dl.eteams.cn/site/bd69a398-a7d3-43a9-af9a-7dafccf5dc25?imageType=png)

4.  切换到右边栏，开启允许用户收缩，选择收缩方式，前端用户就可以进行展开或者收缩。

![](https://dl.eteams.cn/site/56dc6b93-1e2e-491e-bb58-5204e72287cb?imageType=png)

5、开启页面分栏功能，可以设置链接在当前布局展开，如下树形组件。

![](https://dl.eteams.cn/site/06c98ce7-6239-4f69-b29d-9693fa33a4c6?imageType=gif)

节点设置中，编辑动作中打开方式选择当前布局，然后选择展开区域，具体设置如下：

![](https://dl.eteams.cn/site/a1dfc18e-f9cb-4996-b3a1-9d3b66abbf98?imageType=png)
